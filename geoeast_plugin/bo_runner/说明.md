# GeoEast BO Runner 说明

这是 FaultPolyTrace 的 GeoEast 数据库读写集成程序，定位是“可独立运行的 GeoEast 数据桥接器”，用于完成赛题最关键的数据闭环：

1. 连接 GeoEast 数据库和项目。
2. 读取平面断层属性 `BOMapGrid`。
3. 调用 FaultPolyTrace 核心追踪算法。
4. 将闭合断层多边形写回 `BOFaultPolygon`。

## 本机已验证配置

```text
数据库: ndp
项目: BGPCup2026_Test7
用户: 26312
密码: 空
输入网格: test7_fault_attribute_bo
输出多边形: FaultPolyTrace_Result
```

最终建议使用 `test7_fault_attribute_bo`，这是由官方 `test.dat` 通过 runner 导入并验证过的对象。旧对象 `test` 曾出现尺寸和有效像元异常，不应作为最终提交证据。

## 构建方法

推荐从仓库根目录执行：

```powershell
.\scripts\build_geoeast_bo_runner.ps1
```

脚本会设置 GeoEast/NGP/PostgreSQL/Qt 环境变量，并调用 VS2019 的 `msbuild`。如需重新生成 Visual Studio 工程：

```powershell
.\scripts\build_geoeast_bo_runner.ps1 -RegenerateProject
```

工程依赖 GeoEast 官方开发环境中的变量：

- `IECO`
- `NGP`
- `NDPDIR`
- `NGPDIR`
- `GEOEAST`
- `PG_HOME`
- `NGPDATA`

注意：本程序应使用 `/MD` 运行库。使用 `/MDd` 可能在 GeoEast DLL 边界传递 STL 字符串时触发误导性的 `bad allocation` 或 `string too long`。

## 推荐运行

仓库根目录执行：

```powershell
.\scripts\run_geoeast_bgpcup2026_test7.ps1
```

该脚本会：

1. 设置 GeoEast 运行环境。
2. 写入 PostgreSQL `hostname.pg`。
3. 默认从官方 `test.dat` 导入或覆盖 `test7_fault_attribute_bo`。
4. 运行 Ridge-Belt 追踪。
5. 写入 `FaultPolyTrace_Result`。

只读取库内已有网格、不重新导入 DAT：

```powershell
.\scripts\run_geoeast_bgpcup2026_test7.ps1 -NoImportDat
```

## 手动命令示例

```powershell
.\faultpolytrace_geoeast_runner.exe --db ndp --project BGPCup2026_Test7 --user 26312 --password "" --grid test7_fault_attribute_bo --output FaultPolyTrace_Result
```

列出库内网格：

```powershell
.\faultpolytrace_geoeast_runner.exe --db ndp --project BGPCup2026_Test7 --user 26312 --password "" --list-grids
```

验证指定网格：

```powershell
.\faultpolytrace_geoeast_runner.exe --db ndp --project BGPCup2026_Test7 --user 26312 --password "" --grid test7_fault_attribute_bo --validate-grid
```

## 默认算法参数

```text
trace-mode: ridge-belt
threshold-mode: percentile
percentile: 0.98
close-radius: 1
belt-radius: 2
min-branch-length: 6
max-gap-distance: 8
max-gap-angle: 45
simplify-tolerance: 5
smooth-iterations: 1
min-area: 200
```

这些参数来自官方 `test.dat` 的离线基准验证，核心处理时间约 5 到 7 秒，明显低于赛题 1 分钟要求。

## GeoEast 本地注意事项

本机 PostgreSQL 主机文件路径：

```text
C:\Users\26312\GeoEast\NGP\support\PostgreSQL\product\network\hostname.pg
```

工作内容：

```text
ndp=127.0.0.1:5433
```

如果 GeoEast `平面成图` 显示 `There is no license for GeoMapping`，这是 GeoMapping 授权问题，不影响本程序读写 GeoEast 数据库。当前本机 license 到期日为 `20251202`，因此 2026 年需要更新官方 license 后才能补 GeoEast 内部成图截图。
