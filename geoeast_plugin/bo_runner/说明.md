# GeoEast BO Runner 说明

这是 FaultPolyTrace 的 GeoEast 数据库读写集成程序，定位是“可独立运行的 GeoEast 数据桥接器”，用于完成赛题最关键的数据闭环：

1. 连接 GeoEast 数据库和项目。
2. 读取平面断层属性 `BOMapGrid`。
3. 调用 FaultPolyTrace 核心追踪算法。
4. 将闭合断层多边形写回 `BOFaultPolygon`。

## 配置原则

Runner 不内置某台机器的用户名、项目名、网格名或数据路径。所有业务对象都应通过命令行参数、环境变量或 Qt 启动器界面传入。

常用环境变量包括：

- `FPT_GEOEAST_ROOT`：GeoEast 安装根目录。
- `FPT_GEOEAST_DATA_ROOT`：GeoEastData 数据根目录。
- `FPT_GEOEAST_DB`：数据库名，通常为 `ndp`。
- `FPT_GEOEAST_PROJECT`：当前工区项目名。
- `FPT_GEOEAST_USER`：GeoEast 用户名。
- `FPT_GEOEAST_GRID`：输入 `BOMapGrid` 名称。
- `FPT_OFFICIAL_DAT`：需要导入的 DAT 文件路径，仅用于测试或演示。

赛题官方 `test.dat` 可以作为验收数据，但不作为客户机默认配置写入程序。

## 构建方法

推荐从仓库根目录执行：

```powershell
.\scripts\build_geoeast_bo_runner.ps1
```

脚本会设置 GeoEast/NGP/PostgreSQL/Qt 环境变量，并调用 VS2019 的 `msbuild`。如需重新生成 Visual Studio 工程：

```powershell
.\scripts\build_geoeast_bo_runner.ps1 -RegenerateProject
```

工程依赖 GeoEast 官方开发环境中的变量：

- `IECO`
- `NGP`
- `NDPDIR`
- `NGPDIR`
- `GEOEAST`
- `PG_HOME`
- `NGPDATA`

注意：本程序应使用 `/MD` 运行库。使用 `/MDd` 可能在 GeoEast DLL 边界传递 STL 字符串时触发误导性的 `bad allocation` 或 `string too long`。

## 推荐运行

仓库根目录执行：

```powershell
.\scripts\run_geoeast_bgpcup2026_test7.ps1
```

该脚本会：

1. 设置 GeoEast 运行环境。
2. 写入 PostgreSQL `hostname.pg`。
3. 按参数或环境变量选择是否导入 DAT 并写入指定 `BOMapGrid`。
4. 运行 Ridge-Belt 追踪。
5. 写入指定 `BOFaultPolygon` 输出对象。

只读取库内已有网格、不重新导入 DAT：

```powershell
.\scripts\run_geoeast_bgpcup2026_test7.ps1 -NoImportDat
```

如果脚本无法自动识别项目、用户或网格，应显式传入：

```powershell
.\scripts\run_geoeast_bgpcup2026_test7.ps1 -Project <项目名> -User <用户名> -Grid <BOMapGrid名称> -OfficialDat <test.dat路径>
```

## 手动命令示例

```powershell
.\faultpolytrace_geoeast_runner.exe --db ndp --project <项目名> --user <用户名> --password "" --grid <BOMapGrid名称> --output FaultPolyTrace_Result
```

列出库内网格：

```powershell
.\faultpolytrace_geoeast_runner.exe --db ndp --project <项目名> --user <用户名> --password "" --list-grids
```

验证指定网格：

```powershell
.\faultpolytrace_geoeast_runner.exe --db ndp --project <项目名> --user <用户名> --password "" --grid <BOMapGrid名称> --validate-grid
```

## 默认算法参数

```text
trace-mode: ridge-belt
threshold-mode: percentile
percentile: 0.98
close-radius: 1
belt-radius: 2
min-branch-length: 6
max-gap-distance: 8
max-gap-angle: 45
simplify-tolerance: 5
smooth-iterations: 1
min-area: 200
```

这些参数来自官方数据和多组综合诊断的当前推荐值。实际生产数据可根据属性强度、断层密度和面积过滤要求微调。

## GeoEast 本地注意事项

PostgreSQL 主机文件路径通常为：

```text
<GeoEast安装根目录>\NGP\support\PostgreSQL\product\network\hostname.pg
```

工作内容：

```text
ndp=127.0.0.1:5433
```

如果 GeoEast `平面成图` 显示 `There is no license for GeoMapping`，这是 GeoMapping 授权问题，不影响本程序读写 GeoEast 数据库。应使用与当前 GeoEast 版本和年份匹配的有效 license。
