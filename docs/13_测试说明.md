# 第13章 测试说明

## 13.1 测试目标

FaultPolyTrace 的测试目标包括功能正确、算法质量、拓扑合法、性能达标、界面可用、发布可移植和 GeoEast 现场可验证。由于赛题评分同时关注算法、界面、集成、文档和性能，测试不能只跑单一命令。

## 13.2 常用测试脚本

| 脚本 | 作用 |
|---|---|
| `scripts/run_smoke_test.ps1` | 快速烟测核心程序。 |
| `scripts/性能回归检查.ps1` | 检查核心耗时是否满足门禁。 |
| `scripts/检查参数一致性.ps1` | 检查 GUI 与 CLI 参数是否一致。 |
| `scripts/检查独立软件界面功能.ps1` | 检查独立软件按钮、菜单、文档入口和运行链路。 |
| `scripts/检查GeoEast插件界面功能.ps1` | 检查 GeoEast 启动器界面逻辑。 |
| `scripts/验收独立软件发布包.ps1` | 检查发布包结构、依赖和入口。 |

| `scripts/运行完整泛化验证.ps1` | 运行平面精确真值和公开真实剖面辅助压力测试。 |

## 13.4 测试数据原则

官方 `test.dat` 是质量验收主数据。合成数据用于快速检查软件是否能启动、参数是否能传递、异常提示是否正常和基本算法是否可运行。不能因为合成数据通过就认为赛题质量达标，也不能用某一次历史高召回实验结果替代当前推荐主线。

## 13.5 人工测试项

GeoEast 现场已完成菜单入口、启动器自动配置、输入网格列表、原始网格显示、结果多边形图层、叠加图、数据库写入、删除二次确认、显示样式、语言切换和运行日志等操作取证。提交前仍应使用最终发布二进制复核参数模板、日志保存、结果摘要和透明度显示，并按 `docs/GeoEast现场截图与演示视频清单.md` 保存证据。

## 13.6 泛化验证结果

80 个独立几何真值的平面案例覆盖八类断层形态，实测 IoU `0.849627`、Precision `0.910329`、Recall `0.934742`、Boundary F1 `0.996784`，零漏对象、零非法拓扑。独立交叉形态存在 10 次对象误合并，是当前全局分支归属的已知限制。

CRACKS/F3 40 个专家标注纵向剖面已完成辅助压力测试，但因输入域和真值语义不同，不能作为赛题平面精度。详细指标、命令和证据边界见 `docs/18_泛化验证与公开数据指南.md`。
