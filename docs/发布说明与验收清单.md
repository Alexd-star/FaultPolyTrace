# 发布说明与验收清单

本文用于本阶段交付自检，目标是让 FaultPolyTrace 达到可评审、可复现、可演示、可部署的工程状态。

## 1. 发布版本

当前推荐发布版本：

```text
FaultPolyTrace_v0.9.26-guided-splitter-ui
```

本版本重点增强“空目录交互引导、可调主界面布局、英文界面完整性、已有结果目录和 GeoEast 写库反馈”：

- 输入网格和已有结果下拉框为空时，会检查配置、列出缺失项或自动刷新，不再表现为点击无响应。
- GeoEast 插件与独立软件的参数区和结果区支持拖动调整宽度，并自动记忆用户设置。
- 补齐结果管理按钮、动态视图区说明、坐标、启动日志和属性色标的英文翻译。
- 独立软件新增已有结果下拉列表。外部文件模式扫描输出目录中的结果 CSV；GeoEast 数据库模式读取当前项目中的 `BOFaultPolygon` 对象。
- GeoEast 插件新增【刷新结果】和【选为当前】，可选择、覆盖或删除已有结果对象。
- GeoEast 模式运行成功后，日志和结果面板明确显示写入对象 `BOFaultPolygon/<输出名称>`，同时保留本地视图缓存路径，便于独立查看和官方图层复核。
- 支持把数据库中已有的 `BOFaultPolygon` 导出为本地 CSV 视图文件，独立软件和 GeoEast 插件均可载入历史结果进行查看。
- 选择外部输入文件后自动载入原始网格；尚未运行追踪时明确提示当前不是处理后的叠加结果。

发布包应包含：

- 离线 CLI：`bin/faultpolytrace.exe`
- Qt 图形启动器：`qt_launcher/faultpolytrace_launcher.exe`
- 评审推荐入口：`01_打开图形界面.cmd`、`02_运行离线演示.cmd`、`03_查看命令行帮助.cmd`

- GeoEast 主控入口插件：`geoeast_plugin/mainframe_plugin/`
- 中文文档：`docs/`
- 官方数据验收结果和图件：`examples/outputs/`
- 构建、运行、质控、部署、打包脚本：`scripts/`

## 6. 质量验收标准

推荐验收门禁：

- 核心追踪耗时小于 60000 ms。
- 官方数据总耗时小于 5000 ms，调试验收可用 `-MaxElapsedMs 8000` 放宽到包含诊断环境波动。
- 开放环为 0。
- 自相交多边形为 0。
- 多边形相交诊断为 0。
- 当前推荐方案保留多边形数量保持在 214 个附近，默认允许偏差 15 个；历史均衡基线仍可用 204 个作为回归锚点。
- 强响应覆盖率不低于 99.0%。
- 弱响应覆盖率不低于 95.5%。
- 非零响应覆盖率作为辅助指标，应保持在 94% 左右或更高。

说明：正式质量评价不以某个固定多边形数量作为唯一标准。多边形数量会随面积阈值、带宽、弱响应延拓和交切处理策略变化，核心应看覆盖率、拓扑、连续性、边界贴合度和性能。

防黏连增强验收标准：

- 只在默认叠合结果存在明确近邻误合并时启用。
- 启用后强响应和弱响应覆盖率不应下降。
- 切分应主要剔除低值或 0 值背景桥。
- 不应产生大量无来源小多边形。
- 必须使用 `scripts\防黏连差异诊断.py` 输出差异报告，并保留带时间戳的实验目录。

## 13. 2026-06-04 后续增强：独立软件真实图层查看与官方 DAT 稳定性

本轮修复独立软件在官方 `D:\BaiduNetdiskDownload\BGPCup2025\test.dat` 上可能卡死或崩溃的问题。根因是旧界面查看逻辑一次性 `readAll` 约 82 MB DAT 文件并拆成大量字符串，导致 UI 主线程内存峰值和响应性风险。当前版本改为流式解析，并按核心算法一致的 Line-X、CMP-Y 坐标方向构造真实网格。
