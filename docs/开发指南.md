# FaultPolyTrace 开发指南

## 1. 赛题定位

本项目对应东方杯开发赛道赛题 7：

**基于平面断层属性的断层多边形自动追踪。**

目标不是做一个离线小演示，而是做成可以在 GeoEast 环境中读入断层属性、自动追踪闭合断层多边形、写回数据库，并带有友好参数界面、结果统计、文档和可复现实验证据的完整软件作品。

赛题核心要求包括：

| 要求 | 工程含义 |
|---|---|
| 基于平面断层属性数据自动追踪 | 输入是二维属性网格，输出是闭合断层多边形 |
| 面积统计与面积阈值过滤 | 每个多边形必须计算面积，并支持用户过滤小多边形 |
| 合理处理断层交切关系 | 至少要检测、诊断交叉；高分目标要提供保守修复策略 |
| 每个多边形闭合 | 输出 GeoEast 前必须做闭合性、拓扑和异常检查 |
| GeoEast 集成 | 能读 `BOMapGrid`，写 `BOFaultPolygon`，并尽量提供 GeoEast 内入口 |
| 友好界面 | 用户可选择输入数据、输出名称和算法参数 |
| 核心算法 1 分钟内完成 | C++ 核心、线性或近线性流程、避免重型依赖 |
| 内存合理、无泄漏 | 使用 RAII 容器，控制网格副本数量，提供压力测试证据 |

## 3. 推荐产品形态

项目应保持三层架构：

1. **核心算法库**
   - `Grid2D`
   - 预处理
   - 分割
   - 连通域
   - 边界追踪
   - 骨架图
   - 多边形构建
   - 拓扑诊断
   - 面积过滤

2. **独立程序和 Qt 启动器**
   - 用于外部文件测试、参数调试和演示。
   - 可调用 GeoEast runner 完成数据库读写。
   - 方便比赛答辩时展示一键运行流程。

3. **GeoEast 集成层**
   - 从 `BOMapGrid` 读取平面断层属性。
   - 向 `BOFaultPolygon` 写入追踪结果。
   - 通过 Qt 界面提供输入选择、输出命名和参数设置。
   - 已补齐 GeoEast 主控菜单或 Ribbon 入口，演示时可从 GeoEast 主界面启动 Qt 启动器。

核心规则：算法库不能依赖 GeoEast 头文件；GeoEast 相关代码必须封装在适配器中。这样算法可以脱离 GeoEast 快速测试，也能降低 SDK 环境问题带来的开发风险。

## 4. 算法路线

赛题图示显示的是黑色平面断层属性脊线被转换成细长闭合断层多边形。单纯把高值区域当作普通 GIS 斑块是不够的，所以最终算法保留两条路线：

| 模式 | 适用情况 | 说明 |
|---|---|---|
| `region` | 断层属性呈较宽片状或块状 | 对高值区域分割后直接追踪外边界 |
| `ridge-belt` | 断层属性呈细长脊线 | 提取骨架中心线，再缓冲成闭合断层带 |

比赛主推 `ridge-belt`，因为它更符合赛题图和地质解释习惯；`region` 作为厚断层带和质量检查的备用模式。

### 4.1 输入数据

内部输入模型：

```text
Grid2D {
  nx, ny
  sx, sy
  dx, dy
  angle
  values[nx * ny]
  invalidValue
}
```

GeoEast 映射目标：

- 输入对象：`BOMapGrid`
- 父对象：`BOProject`
- 头信息：`BAMapGridHead`
- 主要字段：`sx/sy/dx/dy/nx/ny/angle`
- 无效值：通常按 `FLT_MAX` 处理
- 读取接口：`readDataHead`、`readData`

外部文件支持用于调试和复现实验，GeoEast 数据库读写用于满足评分核心项。

### 4.2 预处理

预处理目标是把噪声属性图变成稳定的候选断层结构：

- 无效值掩码。
- 鲁棒归一化。
- 中值滤波，去除孤立噪点。
- 可选高斯平滑。
- 可选线状结构增强。

所有关键参数都应进入日志和诊断 JSON，方便报告中说明“用什么参数得到什么结果”。

### 4.3 分割

当前已支持：

- 固定阈值。
- 分位数阈值。
- 形态学开运算。
- 形态学闭运算。
- 最小面积和最小像元数过滤。

后续增强：

- 局部自适应阈值。
- 双阈值滞后分割。
- 根据属性强度和连通性估计置信度。

### 4.4 闭合边界追踪

当前实现采用活动网格边界提取：

1. 对二值候选区域提取边界边。
2. 按方向拼接成闭合环。
3. 去除冗余共线点。
4. 计算面积、周长和统计信息。
5. 输出前进行闭合性和拓扑诊断。

这种方法已经替代早期凸包近似，能够保留凹形边界，这是断层多边形追踪质量的关键。

下一步几何增强：

- 支持孔洞和多环结构。
- 增加 Douglas-Peucker 简化。
- 可选 marching squares 插值，让边界更平滑自然。
- 增加更完整的自相交修复。

### 4.5 Ridge-Belt 追踪

`ridge-belt` 当前主流程：

1. 对属性网格进行阈值分割。
2. 对候选区域做形态学清理。
3. 骨架化得到中心线。
4. 提取端点、交点和分支。
5. 剪除短分支。
6. 按距离和方向补连断裂端点。
7. 以用户设置的 `beltRadius` 缓冲中心线。
8. 复用边界追踪器生成闭合多边形。
9. 面积过滤并写出结果。

主要参数：

| 参数 | 含义 |
|---|---|
| `--trace-mode ridge-belt` | 使用骨架转断层带模式 |
| `--threshold-mode percentile` | 使用分位数阈值 |
| `--percentile 0.98` | 取高值属性作为候选断层 |
| `--close-radius 1` | 连接近距离断裂 |
| `--belt-radius 3` | 断层带半宽，单位为网格像元 |
| `--min-branch-length 4` | 删除短分支噪声 |
| `--max-gap-distance 12` | 端点最大补连距离 |
| `--max-gap-angle 55` | 端点补连最大方向差 |
| `--no-residual-trace` | 正式主线默认关闭残余二次追踪 |
| `--residual-trace-min-length 6` | 残余二次追踪最短线性长度，高召回复核时生效 |
| `--residual-trace-max-cells 80` | 残余二次追踪单块规模上限，高召回复核时生效 |
| `--min-area 120` | 输出最小面积阈值 |

### 4.6 面积过滤

每个多边形至少记录：

- `id`
- `status`
- 面积
- 周长
- 点数
- 来源像元数
- 平均属性值
- 最大属性值

`status` 为：

- `kept`：达到面积阈值，参与输出。
- `filtered`：小于面积阈值，仅用于统计或诊断。

### 4.7 断层交切处理

交切关系是高分差异点。当前项目已有拓扑诊断基础，后续应继续加强：

1. 建立线段索引。
2. 检测线段相交和多边形相交。
3. 按面积、长度、平均属性强度、置信度排序主次断层。
4. 默认采用保守策略：检测和报告，不主动破坏解释结果。
5. 可选策略：吸附、截断、分割或裁剪低优先级多边形。
6. 输出交切处理统计，写入最终报告。

比赛交付最低要求是可靠检测和结果说明；冲高分应实现保守修复并提供可视化前后对比。

### 5.1 GeoEast 输入对象

平面断层属性应优先按 `BOMapGrid` 读取。程序需要从 GeoEast 项目中拿到指定网格对象，读取头信息和数据值，再转换为 `Grid2D`。

### 5.2 GeoEast 输出对象

输出采用 `BOFaultPolygon`。关键结构包括：

- `BAFaultPolygonPoint`
- `BAFaultPolygonSegment`
- `BAFaultPolygonData`
- `BAFaultPolygonHead`

核心写出接口：

```text
saveData(head, data)
```

### 5.3 当前 GeoEast Runner

GeoEast 数据库桥接程序位于：

```text
geoeast_plugin/bo_runner
```

用途：

1. 连接 GeoEast 数据库和项目。
2. 读取用户选择的 `BOMapGrid`。
3. 调用 C++ 追踪核心。
4. 将保留的多边形写为 `BOFaultPolygon`。

### 5.4 Qt 启动器

Qt 启动器位于：

```text
geoeast_plugin/qt_launcher
```

作用：

- 填写 GeoEast 根目录、数据根目录、数据库、项目、用户。
- 刷新并选择输入网格。
- 设置输出多边形对象名。
- 导入或覆盖官方 DAT。
- 配置算法参数。
- 运行追踪并查看日志。
