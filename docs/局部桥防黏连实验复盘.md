# 局部桥防黏连实验复盘

文档版本：V1.0  
日期：2026-05-23  
适用对象：FaultPolyTrace 赛题 7 冲顶质量复核、算法答辩和后续产品化开发

## 1. 为什么做这个实验

用户在叠合图中标出了疑似黏连区域。复核后确认：部分大多边形确实可能把邻近但不同脉络的断层包在同一个闭合区域内。这个问题不能靠简单调大或调小带宽解决，因为：

- 带宽太大，会提高覆盖率，但更容易把近邻断层包成大圈。
- 带宽太小，会减少黏连，但会漏掉弱响应和断层端部。
- 最终 WKT 多边形层硬切会产生不自然长边，曾导致覆盖率明显下降。

因此本轮新增了一个默认关闭的实验开关：`localAntiMerge`。它在 `activeMask` 掩膜层、生成闭合多边形之前工作，只尝试切除低属性背景窄桥。

## 2. 实现方式

新增参数：

```text
--local-anti-merge
--no-local-anti-merge
--local-anti-merge-low-threshold
--local-anti-merge-bridge-radius
--local-anti-merge-min-part-cells
--local-anti-merge-min-part-ratio
--local-anti-merge-min-bridge-cells
--local-anti-merge-min-low-ratio
```

默认值：

```text
localAntiMerge = false
localAntiMergeLowThreshold = 0.05
localAntiMergeBridgeRadius = 2
localAntiMergeMinPartCells = 80
localAntiMergeMinPartRatio = 0.08
localAntiMergeMinBridgeCells = 6
localAntiMergeMinLowRatio = 0.55
```

算法流程：

1. 在脊线缓冲、属性包络约束、带后闭合之后得到 `activeMask`。
2. 对每个连通断层带统计低属性像元比例。
3. 只对低属性比例达到阈值的连通体做局部检查。
4. 将 `value <= localAntiMergeLowThreshold` 的像元视为低属性背景候选。
5. 去掉低属性像元后，寻找两个以上足够大的非低值主体。
6. 只把同时靠近两个以上有效主体的低值像元作为窄桥候选。
7. 模拟切开后，如果不能形成两个以上有效主体，则自动回退。
8. 切分通过后再追踪闭合边界、计算面积、做拓扑诊断。

## 4. 视觉复核结论

局部窄桥方案：

- 多边形 34 被拆分为两个更自然的片段。
- 没有损失强响应或弱响应像元。
- 但没有解决 52、67、126 等最大疑似黏连对象。
- 高风险误合并候选没有减少，说明它不是完整解决方案。

根系增强方案：

- 能拆分 67、126、40、33 等对象，更接近“沿同一根系才能归并”的思路。
- 多边形数量从 204 增至 209，仍保持 200 个量级。
- 覆盖率和拓扑不下降。
- 126 的差异诊断提示 1 个弱响应像元可能被边界变化影响，应作为中风险复核点记录。

## 5. 当前产品策略

正式默认仍保持：

```text
rootAntiMerge = false
localAntiMerge = false
residualTrace = false
```

原因：

- 默认主线覆盖率、拓扑、速度、多边形数量最稳定。
- 赛题评分首先要求自动追踪、闭合、面积过滤、GeoEast 读写和性能达标。
- 防黏连增强属于冲顶复核能力，不应悄悄改变默认结果。

高级复核建议：

```text
rootAntiMerge = true
rootAntiMergeSupportRatio = 0.25
rootAntiMergeMinPartRatio = 0.12
localAntiMerge = false
```

局部桥防黏连建议暂定为实验开关：

```text
localAntiMerge = true
```

仅用于算法调试和候选对照，暂不建议交给普通用户默认使用。

## 6. 后续方向

1. 保留 `localAntiMerge` 代码和诊断字段，作为可回溯实验能力。
2. 不把局部窄桥并入默认主线。
3. 继续加强根系增强的切后验收，重点降低 126 这类中风险弱响应边界损失。
4. 将蓝框局部图、差异诊断和根系增强对照写入答辩材料。
5. 后续若要继续冲顶，应在骨架主干归属阶段改进，而不是继续在最终多边形层硬切。
