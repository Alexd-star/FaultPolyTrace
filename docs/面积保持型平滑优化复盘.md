# 面积保持型平滑优化复盘

文档版本：V1.0  
日期：2026-05-22  
适用对象：FaultPolyTrace 赛题 7 正式主线、算法答辩和后续质量优化

## 1. 问题现象

在 2026-05-22 的冲顶质量复核中，正式主线已经达到较高质量：

```text
保留多边形：204
强响应覆盖率：99.5236%
弱响应覆盖率：96.6313%
开放环/自相交/多边形异常相交：0/0/0
```

但顶尖质量诊断仍提示 3 个强响应未覆盖复核连通域。查看局部图后发现，这些区域主要集中在：

- 断层端点附近。
- 数据边界附近。
- 交切或分支过渡位置。

它们不是大范围主干断层漏追踪，而是局部高属性像元落在平滑边界外。

## 2. 根因定位

为避免盲目调参，本轮固定主追踪参数，只改变几何后处理：

| 方案 | 多边形 | 强响应覆盖率 | 弱响应覆盖率 | 拓扑 |
|---|---:|---:|---:|---|
| 旧主线：简化 2 + 平滑 1 | 204 | 99.5236% | 96.6313% | 0/0/0 |
| 关闭平滑 | 204 | 99.5563% | 96.7235% | 出现自相交和多边形相交 |
| 关闭简化、保留平滑 | 204 | 99.5236% | 96.6313% | 0/0/0 |
| 原始边界 | 204 | 99.5563% | 96.7235% | 出现自相交和多边形相交 |

结论：

- 关闭平滑后覆盖率略有提升，说明主追踪掩膜本身覆盖更完整。
- 关闭平滑会破坏拓扑，说明不能简单取消平滑。
- 简化不是主要原因。
- 根因是普通 Chaikin 平滑会让闭合多边形边界轻微向内收缩。

## 3. 修复方案

本轮实现“面积保持型平滑”，只修改几何后处理，不改变断层识别、阈值、骨架、补连和面积过滤逻辑。

处理流程：

```text
原始闭合边界
    ↓
Douglas-Peucker 简化
    ↓
Chaikin 平滑
    ↓
计算平滑前后面积
    ↓
若平滑后面积缩小，则围绕平滑后多边形质心做有限比例补偿
    ↓
重新计算面积、周长和拓扑
```

关键约束：

- 只在平滑后面积小于平滑前面积时触发。
- 补偿比例有上限，防止无约束外扩。
- 不降低阈值，不启用残余二次追踪，不增加碎片层。
- 所有结果仍进入统一拓扑诊断。

代码位置：

```text
src/core/Polygon.cpp
```

新增的核心逻辑包括：

- `signedArea`：计算有向面积。
- `centroidForScale`：计算用于补偿的多边形质心。
- `compensateSmoothingArea`：执行有限面积补偿。

## 5. 质量判断

本轮修复是正向改进：

- 强响应覆盖率从 99.5236% 提升到 99.6217%。
- 弱响应覆盖率从 96.6313% 提升到 96.9351%。
- 多边形数量仍为 204，没有碎片化。
- 拓扑仍保持 0/0/0。
- 核心耗时仍小于 0.5 秒，远低于赛题 1 分钟要求。

本轮修复不是“官方 test.dat 专用调参”，原因如下：

- 修改的是几何平滑的通用内缩问题。
- 主追踪阈值和骨架逻辑没有针对具体位置改变。
- 没有新增坐标、对象名或图案硬编码。
- 使用面积和质心等通用计算几何量约束补偿。

## 6. 剩余复核点

最新结果仍保留 3 个强响应复核连通域。根据局部图和数值诊断，它们主要属于：

- 数据边界上的短线状高值段。
- 端点附近高值像元。
- 交切附近小块。

下一步不建议继续通过全局降阈值或开启残余追踪来追求表面 100% 覆盖。更合适的方向是：

1. 在漏检质控表中增加最近多边形距离、是否接触边界、是否端点延伸。
2. 对每个强响应复核区域给出“补追踪、边界端点、过滤噪声”分类。
3. 仅对真实连续断层做局部端点补追踪。
4. 保持拓扑、数量和性能门禁不变。

## 7. 后续门禁

以后任何继续优化进入正式主线前，必须满足：

```text
强响应覆盖率 >= 99.6217%，除非有明确地质理由
弱响应覆盖率 >= 96.9351%，除非换用更稳健防误合并预设
保留多边形保持 200 个量级
开放环/自相交/异常相交 = 0/0/0
核心追踪耗时 < 1000 ms，硬门槛 < 60000 ms
不得产生几千个碎片多边形
不得把相邻但无属性支撑的断层合成大圈
```
