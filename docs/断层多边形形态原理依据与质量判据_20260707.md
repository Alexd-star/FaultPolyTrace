# 断层多边形形态原理依据与质量判据

## 1. 文档目的

本文档用于约束 FaultPolyTrace 后续算法优化、参数判断、图件复核和 GeoEast 集成工作。后续不允许仅凭“视觉上更好”或“某个 polygon 编号特殊”修改算法；所有修形、拆分、降级、保留和回退都必须能回到以下四类依据：

1. 地质解释原理依据；
2. 地震属性与自动断层解释论文依据；
3. 成熟解释软件产品实践依据；
4. 本项目自动化质量门禁依据。

## 2. 权威资料与产品实践依据

### 2.1 断层多边形的工程用途

成熟解释软件中，断层多边形不是单纯的视觉线条，而是用于约束构造解释、平面成图、网格处理和结果复核的重要对象。DUG Insight 文档明确将 fault polygons 用于解释约束，使相关解释过程避开断层影响区域。SLB Petrel 的结构与断层分析模块强调断层映射、断层属性和解释质量检查。这说明断层多边形必须具备清晰可解释的边界、可编辑性和拓扑可靠性。

### 2.2 多边形应表达断层带，而不是任意高值斑块

Petrel 相关建模资料中，fault polygon 通常由同一层面上的 hanging wall line 和 footwall line 定义。这对本项目的启发是：断层多边形应围绕断层响应带形成成对边界，表达一条断层或断层带在平面上的影响范围，而不是把相邻但不同脉络的高值响应随意合并成一个大面。

### 2.3 断层解释需要对象归属和连续性控制

DUG Insight 和 OpendTect 都支持 faults、polygons 等对象组织。相关软件资料说明解释对象需要在结构关系更清楚时进行合并、拆分或归属。这支持本项目的“根系/分支归属”思想：近邻响应不能仅按距离合并，应考虑是否属于同一线性脉络、同一根系或同一分支系统。

### 2.4 地震属性辅助断层解释的算法依据

SEG 论文《Semi-automated fault interpretation based on seismic attributes》提出使用 coherence/discontinuity 等属性作为输入，先二值化潜在断层位置，再进行骨架化和解释对象组织。论文同时指出窗口过大会涂抹断层信息，窗口过小则对噪声敏感。这对本项目有两个约束：

1. 不能通过全局加粗、全局闭运算或全局降阈值追求表面覆盖率；
2. 必须把骨架、属性支撑、局部窗口和噪声敏感性一起纳入质量门控。

## 3. 本项目质量判据

### 3.1 必须满足的基础几何质量

正式输出的断层多边形必须满足：

| 判据 | 要求 |
|---|---|
| 闭合性 | 多边形必须闭合 |
| 有效性 | 不应出现无效 WKT、空几何或非多边形几何 |
| 自相交 | 不允许自相交 |
| 异常相交 | 不允许不同多边形异常面积相交 |
| 可显示性 | 能在 GeoEast/独立软件中作为图层清晰显示 |
| 可回溯性 | 每次结果必须保留输入、参数、输出和图件证据 |

### 3.2 覆盖与误合并的优先级

本项目目标不是机械追求 100% 覆盖率，而是：

```text
覆盖该覆盖的断层响应、少漏检、少误合并、闭合拓扑干净、边界自然、数量粒度符合解释习惯。
```

其中优先级为：

1. 拓扑有效；
2. 不把不同脉络的近邻断层误合并；
3. 覆盖强响应主干；
4. 覆盖合理弱响应；
5. 局部形态自然；
6. 数量粒度符合解释习惯。

### 3.3 不应强行处理的情况

以下情况不应被简单当作错误：

| 情况 | 处理策略 |
|---|---|
| Y 字分支交切 | 若有 3 条及以上独立响应臂进入候选区，应标记为分支交切复核，而不是强裁 |
| 长段宽断层带 | 若宽化沿主干长距离稳定存在，应进入长段宽带复核，不应局部瘦身 |
| 强响应夹持内环 | 若内环两侧存在连续强响应，可能是真实双线夹持空隙，应降为复核 |
| 边界截断 | 不默认外推，防止造假断层 |
| 弱线性残余 | 可进入残余复核层，不默认并入正式层 |

### 3.4 应优先处理的情况

以下情况可以作为自动优化候选：

| 情况 | 处理策略 |
|---|---|
| 局部囊状鼓包 | 候选框内瘦身或支撑裁剪，候选框外不动 |
| 低支撑桥接 | 若两侧有独立属性支撑分支，可局部拆分 |
| 单分支证据不足 | 必须回退 |
| 删除面积过大 | 必须回退 |
| 修后覆盖率下降 | 必须回退 |
| 修后拓扑异常 | 必须回退 |

## 4. 参数与图件判断原则

### 4.1 参数不能脱离物理与解释意义

参数必须对应明确含义：

| 参数类别 | 解释意义 |
|---|---|
| 阈值/百分位 | 表示断层属性响应强弱 |
| belt radius | 表示断层带半宽 |
| min area/min cells | 表示最小可解释对象粒度 |
| root anti-merge | 表示不同线性脉络之间的防误合并 |
| support ratio | 表示候选修形后仍保留的属性支撑比例 |
| branch arm count | 表示候选区边界上独立响应臂数量 |

### 4.2 图件必须服务于复核

图件分为四类：

1. 官方风格叠加图：用于看覆盖；
2. 纯多边形图：用于看拓扑和形态；
3. 分块图：用于全图逐块排查；
4. 候选局部图：用于解释候选为何处理或保留。

候选框、黄色框、风险框只能用于复核图，不能混入正式效果展示图。

## 5. 后续开发门禁

任何新规则进入正式线前必须通过：

1. 官方 `test.dat` 指标不退化；
2. 拓扑核验全 0；
3. 泛化回归验证通过；
4. 图件逐块复核无新增明显问题；
5. 文档说明能追溯到地质解释、论文或成熟软件实践依据；
6. 若进入 GeoEast，必须通过 GeoEast 写入、图层显示和用户操作验证。
