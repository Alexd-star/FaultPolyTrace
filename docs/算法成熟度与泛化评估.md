# 算法成熟度与泛化评估

文档版本：V1.0  
日期：2026-05-05  
适用项目：FaultPolyTrace 断层多边形自动追踪

## 1. 结论

当前 FaultPolyTrace 不是官方 `test.dat` 专用程序。核心算法未写死官方数据路径、坐标范围、线条位置、对象名或特定多边形形状。软件使用通用二维网格处理流程，包括分位数阈值、形态学处理、弱响应延拓、骨架化、骨架图分析、端点补连、断层带缓冲、属性约束、多外环边界追踪、面积过滤和拓扑诊断。

当前版本可以作为赛题正式交付版本，并具备基础产品化能力。但从严格商业产品角度，仍应继续增加真实多区块回归数据、人工解释对照和参数自动推荐。更准确的成熟度判断是：

```text
比赛交付：成熟，可用于正式演示和答辩
工程原型：成熟，具备独立运行和 GeoEast 集成能力
企业级产品：已具备核心基础，仍需真实项目数据持续验证和产品闭环增强
```

## 2. 当前最佳结果如何得到

当前推荐结果采用 `贴合融合推荐` 参数，不是通过硬编码官方数据得到，而是经过算法机制逐步修正形成：

1. 使用 `Ridge-Belt` 主流程，从断层属性中提取线性脊线，再扩展为闭合断层带。
2. 使用分位数阈值代替固定阈值，使不同属性幅值的数据也能自动确定强响应。
3. 引入弱响应延拓，解决断层属性强弱变化导致的断续问题。
4. 使用骨架图识别端点、交点和分支，剪除短毛刺，保留交切处高属性短分支。
5. 使用端点方向和距离约束进行保守补连，减少断层被切碎。
6. 使用属性约束断层带，使缓冲后的多边形不脱离原始属性响应。
7. 修正多外环边界追踪，避免一个连通组件中多个有效外环只保留最大环的问题。
8. 将 GeoEast DAT 样点解释为网格中心，输出多边形边界使用网格边界，减少半个网格的系统偏移。
9. 使用白底质量图和漏检质控图检验覆盖率、弱响应残留和拓扑问题。

这些步骤都是通用图像/网格几何算法和断层属性解释逻辑，不依赖官方数据的具体图案。

## 3. 当前推荐参数是否属于过度调参

当前参数确实经过多轮试验确定，但不属于“只对一个样例碰巧有效”的调参。原因如下：

- 参数含义均有明确地质或几何解释。
- 阈值采用分位数，适配不同属性幅值。
- 弱响应延拓受强响应邻域、连通域大小和长宽比约束，避免无条件吞噬背景。
- 端点补连受距离和方向约束，避免任意连接。
- 属性约束断层带限制了缓冲范围，避免边界过宽。
- 面积阈值只影响保留/过滤，不改变核心识别逻辑。
- 拓扑诊断独立检查开环、自交和多边形相交。

也就是说，参数是对通用算法策略的配置，而不是对某条官方线段的位置修补。

## 5. 当前算法的可靠点

### 5.1 理论基础可靠

核心处理流程对应明确的图像处理和计算几何方法：

- 分位数阈值分割。
- 形态学闭运算。
- 连通域分析。
- Zhang-Suen 骨架化。
- 骨架图端点、交点、分支分析。
- 方向约束端点补连。
- 骨架缓冲形成断层带。
- 属性包络约束。
- 边界环追踪。
- Douglas-Peucker 简化。
- Chaikin 平滑。
- 拓扑相交诊断。

### 5.2 工程逻辑可靠

- 核心算法与 GeoEast SDK 解耦。
- 外部文件和 GeoEast 数据库均可运行。
- 输出包含 CSV、WKT、诊断 JSON、分支 CSV、拓扑 CSV。
- 自动验收脚本可复现结果。
- 官方数据默认稳健方案核心耗时约 2.17 秒，总耗时约 3.14 秒。
- 官方数据强响应覆盖率约 85.33%，弱响应覆盖率约 86.90%，该覆盖率按最终闭合多边形区域统计，口径比早期候选带覆盖率更严格。

### 5.3 未发现官方样例硬编码

代码中不存在以下特化：

- 针对 `test.dat` 文件名的算法分支。
- 针对官方坐标范围的裁剪或补丁。
- 针对某条断层位置的手工连线。
- 针对某个固定多边形数量的输出逻辑。
- 针对官方图片的图像模板匹配。

## 6. 当前仍需承认的边界

当前版本还不能宣称已经覆盖所有真实地质场景。主要边界包括：

1. 交切断层如果在属性图上天然连成一个网络，当前默认会输出连通网络带，而不是强制拆成多条独立断层。
2. 很细、很短、属性很弱的残余线段会被质控标出，但默认不一定生成独立多边形。
3. 不同工区属性幅值、噪声水平、采样间隔和断层尺度差异较大，仍需要参数预设或自动推荐。
4. 目前泛化验证包含合成数据，但真实企业级产品还需要多工区真实数据、人工解释真值和版本化回归集。
5. 平面断层属性本身可能包含非断层线性噪声，算法不能替代地质解释人员的最终质控。

## 7. 后续产品化增强方向

为了从比赛级优秀作品进一步升级为企业级产品，建议后续增强：

1. 参数自动推荐：根据属性直方图、连通域尺度、线性程度自动选择预设。
2. 残余线性响应二次追踪：对漏检质控中的细长高值残余进行受控补追踪。
3. 分支级交切拆分：在交切网络内按骨架分支输出可选独立断层带。
4. 真实数据回归库：积累不同工区、不同属性类型、不同采样间隔的验收样本。
5. 交互式质控：允许用户在 GeoEast 中查看漏检区域、过滤原因和分支保留原因。
6. 自动报告：一键输出算法参数、质量图、漏检表、性能统计和 GeoEast 截图清单。
