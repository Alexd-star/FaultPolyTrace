# 算法成熟度与泛化评估

文档版本：V1.1  
日期：2026-05-22  
适用项目：FaultPolyTrace 断层多边形自动追踪

## 1. 总体结论

FaultPolyTrace 当前不是官方 `test.dat` 专用程序。核心算法未写死官方数据路径、坐标范围、线条位置、对象名或固定多边形形状。软件采用通用二维网格处理流程，包括分位数阈值、弱响应延拓、骨架图分析、端点补连、属性约束断层带、多外环边界追踪、面积过滤、边界平滑和拓扑诊断。

当前成熟度判断如下：

```text
比赛交付：强基线，已具备正式演示和答辩能力
工程原型：成熟，具备独立运行、Qt 启动器和 GeoEast 读写集成能力
企业级产品：已具备核心基础，但仍需自动参数推荐、误合并诊断和更多真实工区回归
```

也就是说，项目已经达到“可以提交并有竞争力”的状态，但如果按真正商业软件标准，还不能宣称已经覆盖所有真实地质场景。

## 2. 当前正式主线如何得到

当前正式主线采用“贴合融合推荐”参数，不靠硬编码官方样例，而是由一套通用追踪流程逐步形成：

1. 使用 `Ridge-Belt` 主流程，从断层属性中提取线性脊线，再扩展为闭合断层带。
2. 使用分位数阈值代替固定阈值，使不同属性幅值的数据也能自动确定强响应。
3. 引入弱响应延拓，减少断层属性强弱变化造成的断续。
4. 使用骨架图识别端点、交点和分支，剪除短毛刺，保留交切附近高属性短分支。
5. 使用端点方向、距离和属性支撑进行保守补连。
6. 使用属性约束断层带，使缓冲后的多边形不明显脱离原始属性响应。
7. 使用多外环边界追踪，避免一个连通组件中多个有效外环只保留最大环。
8. 将 GeoEast DAT 样点解释为网格中心，输出多边形边界使用网格边界，减少半个网格的系统偏移。
9. 使用白底质量图、漏检质控图、拓扑 CSV 和诊断 JSON 做复核。

这些步骤是通用图像处理、骨架拓扑和计算几何逻辑，不依赖官方数据的具体图案。

## 4. 当前参数是否属于过度调参

当前参数经过多轮试验确定，但不属于“只对一个样例碰巧有效”的调参。原因如下：

- 阈值采用分位数，适配不同属性幅值。
- 断层带宽度、补连距离、分支长度等参数都有明确几何意义。
- 弱响应延拓受强响应邻域、连通域规模和长宽比约束。
- 端点补连受距离、方向和支持像元比例约束。
- 属性约束断层带限制了缓冲范围，避免边界过宽。
- 面积阈值只影响保留/过滤，不改变核心识别逻辑。
- 面积保持型平滑只修复边界平滑造成的系统性收缩，不改变断层主追踪阈值和骨架结构。
- 拓扑诊断独立检查开放环、自交和多边形相交。

仍需承认的是：当前默认参数是在官方数据和合成数据上校准过的推荐值。企业级产品还应加入参数自动推荐，让软件根据属性直方图、网格间距、断层尺度和噪声水平自动选择预设。

## 6. 当前可靠点

### 6.1 理论基础可靠

核心处理流程对应明确算法：

- 分位数阈值分割。
- 形态学闭运算。
- 连通域分析。
- Zhang-Suen 骨架化。
- 骨架图端点、交点、分支分析。
- 方向约束端点补连。
- 骨架缓冲形成断层带。
- 属性包络约束。
- 边界环追踪。
- Douglas-Peucker 简化。
- Chaikin 平滑。
- 拓扑相交诊断。

### 6.2 工程逻辑可靠

- 核心算法与 GeoEast SDK 解耦。
- 外部文件和 GeoEast 数据库均可运行。
- 输出包含 CSV、WKT、诊断 JSON、分支 CSV、拓扑 CSV。
- Qt 启动器支持输入、输出、参数、颜色和日志。
- 自动验收脚本可复现结果。
- 当前正式主线核心耗时低于 1 秒，远低于赛题 1 分钟要求。

### 6.3 未发现官方样例硬编码

代码中不存在以下特化：

- 针对 `test.dat` 文件名的算法分支。
- 针对官方坐标范围的裁剪或补丁。
- 针对某条断层位置的手工连线。
- 针对某个固定多边形数量的输出逻辑。
- 针对官方图片的模板匹配。

## 7. 当前仍需承认的边界

1. 如果属性图上多个断层天然连成高值网络，默认主线会优先输出连续断层带，而不是强制拆成多条独立地质断层。
2. 很细、很短、属性很弱的残余线段会被质控标出，但默认不一定生成独立多边形。
3. 不同工区属性幅值、噪声水平、采样间隔和断层尺度差异较大，仍需要参数自动推荐。
4. 目前真实数据回归样本有限，企业级产品还需要多工区、人工解释真值和版本化回归集。
5. 平面断层属性本身可能包含非断层线性噪声，算法不能替代地质解释人员的最终质控。

## 8. 后续产品化增强方向

为了从比赛级优秀作品进一步升级为企业级产品，建议优先增强：

1. 参数自动推荐：根据属性直方图、线性连通域尺度、网格间距和噪声水平自动选择预设。
2. 局部误合并诊断：检测多边形内部是否存在低属性窄桥、近邻断裂跨背景连接等风险。
3. 残余线性响应复核：把漏检细弱线段输出为复核层，而不是默认混入正式层。
4. 分支级解释输出：给每条分支保留、剪枝、补连的原因，便于答辩和用户信任。
5. 真实数据回归库：积累不同工区、不同属性类型、不同采样间隔的验收样本。
6. 自动报告：一键输出参数、质量图、漏检表、性能统计和 GeoEast 截图清单。
