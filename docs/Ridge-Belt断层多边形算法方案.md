# Ridge-Belt 断层多边形算法方案

官方赛题图显示：黑色平面断层属性脊线被转换为细长闭合断层多边形。本文定义本项目最核心的解释型算法路线。

## 1. 为什么不能只做区域边界

当前区域边界算法已经是一个强基线：

- 对高值断层属性像元进行阈值分割。
- 按连通域分组。
- 追踪闭合边界。
- 计算面积并过滤。

但赛题图和地质解释习惯说明，最终结果更像“围绕断层线的闭合断层带”：

- 原始断层属性通常是细长线状或脊状。
- 输出多边形是沿断层走向分布的窄带。
- 分支、断续、交切关系很重要。

因此最终产品必须包含 Ridge-Belt 路线：先提取断层中心线，再扩展为闭合多边形带。

## 2. 地质形态假设

东方杯属于地质勘探领域，算法不能只适配一张示例图。实际平面断层属性可能出现：

- 长距离连续脊线。
- 短而断续的断层段。
- 分支、马尾状构造。
- 雁列式断层组合。
- 交叉或切割关系。
- 弯曲、弧形、S 形断层。
- 平行、编织状断裂带。
- 厚高值带，而不是单像素细线。
- 属性噪声产生的孤立斑块。
- 低信噪比区域的弱响应或断裂。

设计决策：

- 默认使用 `ridge-belt` 作为主解释模式。
- 保留 `region` 模式处理厚带或块状异常。
- 支持用户选择模式，后续可加入自动模式判断。
- 把分支、断续、交切处理作为一等模块，而不是附加补丁。

这样可以避免作品变成只适配官方示例的窄 demo。

## 3. 目标数据流

```text
平面断层属性网格
  -> 归一化和去噪
  -> 线状/脊状响应增强
  -> 阈值提取候选区
  -> 骨架化为中心线
  -> 分支剪枝和断点补连
  -> 估计断层带宽度
  -> 中心线缓冲成闭合断层带
  -> 边界简化和拓扑修复
  -> 面积过滤
  -> GeoEast BOFaultPolygon 输出
```

## 4. 实现阶段

### 阶段 1：候选掩码

使用已实现的分割能力：

- 固定阈值。
- 分位数阈值。
- 形态学开运算。
- 形态学闭运算。

后续增强：

- 局部自适应阈值。
- 方向性脊线增强。
- 根据局部背景自动调整阈值。

### 阶段 2：骨架化

在二值候选掩码上执行 Zhang-Suen 或 Guo-Hall 细化。

要求：

- 保持线状结构连通性。
- 将厚断层带压缩为一像素中心线。
- 尽量保留端点。
- 输出确定，不受随机因素影响。

当前项目已实现 Zhang-Suen 骨架化。

### 阶段 3：骨架图提取

将骨架像元转换为图结构：

- 节点：端点、交点、采样点。
- 边：节点之间的骨架路径。
- 属性：长度、平均属性、最大属性、方向、置信度。

骨架图用于：

- 删除短毛刺。
- 补连断点。
- 分析分支关系。
- 解释交切关系。
- 为报告输出分支级统计。

当前项目已实现端点、交点和分支提取。

### 阶段 4：剪枝和断点补连

剪枝对象：

- 孤立像元。
- 很短的毛刺分支。
- 低置信度小分支。

补连条件：

- 两个端点距离小于 `maxGapDistance`。
- 两端方向差小于 `maxGapAngle`。
- 补连路径附近有一定属性支撑。

当前项目已实现保守补连：

- 端点距离限制。
- 方向角限制。
- Bresenham 线补连。

### 阶段 5：中心线缓冲

把骨架路径转换为闭合断层带。

当前实现：

- 按 `beltRadius` 在像元空间中对骨架分支做缓冲。
- 得到缓冲二值掩码。
- 复用已有闭合边界追踪器输出多边形。

后续增强：

- 根据局部属性厚度估计宽度。
- 使用几何 offset curve 生成更平滑边界。
- 处理拐角处圆角或斜接。
- 根据属性强度调整宽度。

### 阶段 6：拓扑修复

必须检查：

- 环是否闭合。
- 面积是否有效。
- 是否存在重复顶点。
- 是否自相交。
- 多边形之间是否相交。

修复策略：

- 默认保守：检测并报告。
- 可选吸附近距离顶点。
- 可选在交切处截断或裁剪低置信度断层带。

## 5. 参数说明

| 参数 | 含义 |
|---|---|
| `thresholdMode` | 阈值模式，支持 `fixed` 或 `percentile` |
| `threshold` | 固定属性阈值 |
| `percentile` | 分位数阈值 |
| `openRadius` | 去除孤立噪声 |
| `closeRadius` | 桥接短距离断裂 |
| `skeletonMinBranchLength` | 删除短分支 |
| `maxGapDistance` | 断点补连最大距离 |
| `maxGapAngle` | 断点补连最大方向差 |
| `beltRadius` | 输出断层带半宽 |
| `minArea` | 最终面积过滤阈值 |

官方数据基线参数：

```text
trace-mode: ridge-belt
threshold-mode: percentile
percentile: 0.98
close-radius: 1
belt-radius: 2
min-branch-length: 6
max-gap-distance: 8
max-gap-angle: 45
min-area: 200
```

## 7. 当前限制

- 断层带宽度仍是固定半径，尚未根据局部属性厚度自适应。
- 交切关系主要是诊断，修复策略仍需增强。
- 断点补连提升了中心线连续性，但多边形融合效果仍受 `beltRadius` 和后续拓扑修复影响。
