# FaultPolyTrace 获奖答辩制图样式与逐页配图方案

## 1. 获奖答辩页面的共同做法

根据 10 份获奖队伍字幕及已抽取的视频页面，答辩图件主要遵循以下规律：

1. 背景页用真实应用对象或输入数据说明问题，不用抽象装饰图代替研究对象。
2. 方法页先给总体结构，再放大一个关键局部；图中标签较短，技术解释由讲稿完成。
3. 创新点通常采用前后对照、局部放大、数据流或信号流表达，不使用大段文字描述算法。
4. 测试页使用真实结果、曲线、照片和对比表，关键数字直接放在图旁，不用生成式示意图代替实验结果。
5. 系统页采用一张主架构图配一至两张真实界面或实物图，结构图说明组成，截图说明实际运行状态。
6. 单页信息可以丰富，但必须有明确主次。主图占据主要面积，局部图、图例和指标围绕主图组织。
7. 配色通常控制在三至四种：深色表示主体结构，青绿色表示有效路径或正常数据流，橙色表示待检查或拒绝项，灰色表示背景。

FaultPolyTrace 的页面采用“真实数据负责说明结果，科研示意图负责解释方法”的组合方式。Image 2 图件不承载正式测试数字，所有数值由 PowerPoint 原生文字或真实统计图显示。

## 2. 统一制图标准

- 画布：16:9，最终 PNG 不低于 2560 × 1440。
- 背景：白色或极浅冷灰，不使用深色科技背景。
- 主色：深蓝 `#163A5F`、青绿 `#2B9A9A`、浅蓝 `#D9EAF2`。
- 辅色：灰蓝 `#6C7A89`、橙色 `#D9824B`；红色只表示几何错误。
- 结构：主流程、局部放大、判断条件和前后对照至少包含其中两类。
- 线条：连接方向明确，线宽一致，箭头不穿过节点；不使用装饰性虚线和无含义纹理。
- 文字：生成图仅保留 A、B、C 等分图编号和必要符号；中文、公式、数字由 PowerPoint 原生文字添加。
- 真实性：官方结果、质量指标、性能数据和软件界面不得使用 Image 2 重绘。
- 版面：图片等比缩放，不拉伸；同组对照图使用相同坐标范围和裁切比例。

## 6. Image 2 最终生成任务

### 6.1 P03 自动追踪总体流程

**输出文件**：`P03_自动追踪总体流程_科研复合图.png`

**图件层次**：

1. 主流程保持 A 至 D 四阶段：属性响应、方向骨架、断层带与分支判断、闭合多边形。
2. A 图增加弱缺口局部放大和强弱响应色阶符号。
3. B 图增加端点切线、交点节点和局部方向场插图。
4. C 图增加候选走廊、接受与拒绝路径、局部属性剖面和带宽估计。
5. D 图增加交切区域局部放大，显示相邻对象保持分离。
6. 下方增加闭合、面积、自相交、异常重叠和输出接受的顺序检查，并保留回退箭头。

**生成要求**：同一断层几何必须贯穿 A 至 D；主图占主要面积，局部插图不超过对应分图的三分之一；图中不写真实指标。

### 6.2 P04 强弱响应协同提取

**输出文件**：`P04_强弱响应协同提取_科研复合图.png`

**图件层次**：

1. 上排三联图采用同一坐标范围：原始属性、方向骨架、可变宽断层带。
2. 原始属性图同时显示强响应主体、弱响应缺口、近邻平行对象和稀疏背景。
3. 骨架图显示端点、交点、切线方向和局部方向场。
4. 断层带图显示局部宽度变化、接受的弱路径和拒绝的侧向分支。
5. 下排增加一个属性横剖面、一个方向一致性极坐标插图和一个宽度恢复局部图。

**生成要求**：三幅主图的几何、尺度和裁切完全一致；剖面和极坐标只表现相对关系，不生成数字。

### 6.3 P05 分支归属与防误合并

**输出文件**：`P05_分支归属与防误合并_科研复合图.png`

**图件层次**：

1. 左侧主图展示仅按邻近关系形成的错误短桥和局部鼓包。
2. 右侧主图展示方向约束后的两个独立对象、保留路径和竞争分支。
3. 中央局部插图显示端点切线、转角、距离和宽度量测。
4. 下排显示候选生成、竞争比较、连接尝试和连接后几何复查四步。
5. 使用青绿色表示接受，橙色表示待比较，红色仅表示确认拒绝的误合并。

**生成要求**：左右主图使用相同输入几何；错误连接必须清楚但不过度夸张；连接前后对象数量关系应可辨认。

### 6.4 P06 多边形几何质量检查

**输出文件**：`P06_多边形几何质量检查_科研复合图.png`

**图件层次**：

1. 五类主案例：合法闭合环、开放环、自相交、对象间异常相交、包含或内部重叠。
2. 合法案例增加面积量测和边界方向符号。
3. 错误案例标出具体异常位置，而不是只放叉号。
4. 下方增加从边界生成到有效性检查、对象关系检查和发布结果的顺序流程。
5. 图形采用细长、弯曲、变宽的断层多边形，不使用圆形或普通几何块代替。

**生成要求**：异常位置需要在投影状态下可见；正式结果中的异常数量由 PPT 原生数字添加。

### 6.5 P07 统一核心与双端架构

**输出文件**：`P07_统一核心与双端架构_科研复合图.png`

**图件层次**：

1. 左侧为外部网格文件与独立软件，右侧为 GeoEast 工区、插件和数据库。
2. 两个入口必须汇入一个共享 C++ 核心，不能画成两套并行算法。
3. 核心内部显示属性提取、方向与断层带、分支归属、多边形与几何检查四层职责。
4. 输出同时包括闭合几何、面积统计、DAT/CSV 和 GeoEast 结果对象。
5. 数据库写入单独显示暂存、检查、提交、回读和失败回退五步。
6. 同页另放独立软件和 GeoEast 插件真实截图，生成图不模拟软件界面。

**生成要求**：连接线不得交叉；共享参数只出现一次；数据库事务与普通文件输出使用不同箭头语义。

### 6.6 P12 项目总结主视觉

**输出文件**：`P12_项目总结主视觉.png`

**图件层次**：

1. 从左至右依次表现平面属性网格、方向骨架与断层带、闭合多边形、GeoEast 工区图层。
2. 使用一条连续青绿色路径贯穿四个阶段，表示统一处理流程。
3. 背景保留浅色断层网络纹理，中央和右侧留出总结文字区。
4. 图中包含一处弱响应延伸和一处交切分离的小型细节，呼应两项核心技术。

**生成要求**：信息比封面丰富，但不重复总流程图；不放指标、不放标题、不生成软件界面。

## 7. 生成图质量检查

每张 Image 2 图件生成后执行以下检查：

1. 以全图检查层次是否清楚，再以 100% 比例检查边界、箭头和局部插图。
2. 检查同组分图是否保持相同对象几何，避免流程前后对象位置无故变化。
3. 检查箭头是否穿过对象、局部插图是否遮挡主体、错误颜色是否被用于正常路径。
4. 删除随机文字、乱码、假坐标、假指标和与项目无关的图标。
5. 生成图不能出现真实测试数值；正式数字由 PPT 原生文字添加。
6. 若主图在 16:9 页面中缩放到 60% 后无法辨认，则减少局部插图数量并重新生成，不通过缩小字号解决。
