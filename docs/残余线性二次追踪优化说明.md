# 残余线性二次追踪优化说明

## 背景

根系追踪版本解决了早期算法容易把近邻断裂误合并成大圈的问题，但在官方 `test.dat` 的部分弱响应和细碎线段上，结果会显得偏保守：主要断层带已经被追踪，局部细线仍可能断续或漏掉。

本轮优化的目标是在不退回全局膨胀融合的前提下，提高断层多边形的完整性。核心原则是：只补“有根、有方向、有属性证据”的线状残余，不把空间上靠得近但没有同源关系的断裂硬连起来。

## 算法改进

1. 主追踪仍采用强属性阈值、骨架化、端点续接、交切处分根和根系归属约束。
2. 在主追踪完成后，构建已覆盖区域掩膜，只检查尚未被多边形覆盖的残余属性响应。
3. 残余响应必须满足以下条件才会补成闭合多边形：
   - 位于某个根系归属范围内；
   - 与已有追踪结果相邻或接触；
   - 形态呈线状，最长方向达到最小长度；
   - 最大值或均值达到相对强属性阈值要求；
   - 单个残余块大小不超过上限，避免把大片弱背景吞入结果。
4. 补追踪生成多边形时，会剔除已经覆盖的格点，避免新增多边形压到已有多边形上造成伪交叉。
5. 面积过滤升级为自适应判别：大于用户面积阈值的结果直接保留；小于面积阈值但强度高、形态细长、格点数足够的真实断层段可以保留；低强度孤立噪声仍过滤。

## 双覆盖保护机制

最新版本采用双覆盖机制区分“候选断层带覆盖”和“最终保留多边形覆盖”：

- 候选覆盖用于保护残余追踪，不允许在已经生成过候选断层带的位置周边反复长出边缘碎片。
- 最终覆盖用于计算真实输出覆盖效果，只统计经过面积过滤和自适应保留后的多边形。

这样可以避免两个常见问题：若只看最终覆盖，被面积过滤的小候选会在二次追踪中反复补回来；若只看候选覆盖，部分最终未保留的真实弱线段又可能被误认为已经处理过。双覆盖机制使默认结果更稳定，也让高召回复核模式更可控。

## 使用建议

默认使用“贴合融合推荐”。该设置优先保证不误合并，同时补足一部分细碎弱响应。

如果解释人员希望追得更全，可以把残余二次追踪参数放宽到 `residual-trace-min-length = 5`、`residual-trace-max-cells = 120`，对应验证中的“稍高召回版本”。该版本覆盖更完整，但需要更多人工复核交切和近邻区域。

如果目标是最保守的提交结果，或数据中噪声较强，可以关闭残余二次追踪，保留根系防误合并主结果。
