ASCII 文件格式定义与输入输出
1 综述
ASCII 码数据文件是应用系统最通用的、跨平台的数据存储方式，同时又是最灵
活的存储方式。
适合存储 ASCII 码存储的数据类型很多，几乎所有的数据类型均可以 ASCII 码的
形式进行存储，如地理信息类、地质类、测井类、成图类等数据。
ASCII 码数据的灵活性表现在数据的组织方式千变万化，如行列分布、格式类型、
特殊标识符等。为了适应 ASCII 码数据的这种灵活性，方便数据输入输出，系统采用
先对输入输出格式进行定义。
《ASCII 码数据输入输出》子系统是针对 ASCII 码数据而设计的，主要功能是完
成 GeoEast 系统与外部 ASCII 码文件之间的数据交换任务。系统的地震数据 SEGY 输
入输出是使用 GeoEast 独立交互功能完成，其他少量数据类型的输入输出是单独的，
如 CGM 成果图、剖面等图形文件的输入输出。所以本手册主要是 GeoEast 系统的
ASCII 码数据输入输出的使用说明。
在 GeoEast 系统中，ASCII 码数据输入输出子系统以统一的操作方式和操作流程，
提供对以磁盘为外部存储介质的 ASCII 码文件数据的输入、输出服务。总的来说，它
主要包含以下功能：
 支持地质、测井、成图、底图数据的 ASCII 码数据文件的输入输出，且方便扩充。
 提供方便的格式定义功能，能定义其它软件系统的一些基本 I/O 格式，提供较全
面的数据项选择及文件类型兼容，支持固定格式、自由格式的输入方式。
 对 ASCII 码文件进行浏览和识别。
 提供单文件或同一格式多文件的批量输入和输出功能。
2 主要功能
用户初次登录 GeoEast 系统主控界面时，首先需要建立用户、项目、工区，然后
便可以输入所需要的二维地震测线信息或三维地震测网信息，为后继的处理或解释的
工作做准备。
2.1 模块组成和功能
ASCII 码数据输入输出由两个功能模块组成，实现以下五部分的功能：
1）ASCII 码文件输入。
2）ASCII 码文件输出。
3）ASCII 码文件格式设置与管理工具。
4）ASCII 码文件批量输出。
5）ASCII 码文件批量导入。

支持以下数据类型的输入输出。具体为：
 测量资料：二/三维测网
 井数据：井信息、井曲线、井轨迹、分层数据、岩性数据、油气水数据、
子波数据（目前子波数据只支持批量输出和批量导入，单独的数据加载暂时不
支持）
 速度数据：TV 对
 地质数据：二/三维层位、二/三维断层、断层多边形
 地理信息数据：边界
 图形数据：散点、网格、等值线、任意线轨迹
 切除库数据（Mute）
 VSP 类数据：VSP 时距曲线、VSP 算子集、VSP 极化参数、VSP 静校正量
2.3 ASCII 码数据文件格式
ASCII 码文件格式一般包括文件头和文件体两部分。文件头视数据类型而定，有
些类型的数据可以不设文件头，只定义文件体，如层位等；而有些数据必须定义文件
头，如三维测网等。

GeoEast 67
界面说明：
坐标恢复界面分为三个部分
1、 第一部分为坐标关联表格；
表格内容：当前表格显示一个或多个备份数据保存的坐标系统与目标数据库中
保存的坐标系统对应关系或者创建规则；
表格第一列为备份的坐标系统名称；
表格第三列为指定的一个当前数据库中坐标系统名称，可以是已存在也可以是
不存在的；
表格第二列为第一列和第三列的关联规则；
关联规则：包括三种
Map to ：第一列中的名称与第三列名称作个关联映射，备份数据中所有使用第
一列坐标系统名称的导入后使用第三列的坐标名称；
Create ：根据第一列的坐标名称包含的参数创建一个新的坐标系统名称，名称
为第三列单元格中的名字；备份数据中所有使用第一列坐标系统名称的导入后
使用第三列的坐标名称；
AutoName ： 以 第 三 列 的 名 称 自 动 加 上 当 前 时 间 （ name +
"_yyyyMMdd_hhmmss"）字符串作为新的坐标系统名称，以第一列名称的坐标
系统包含的参数创建一个新的坐标系统；备份数据中所有使用第一列坐标系统
名称的导入后使用这个新的坐标名称；
第三列名称状态显示：
如第三列的名称是系统已存在的，并且坐标参数与第一列完全相同，则名称显
示绿色，关系自动改为 Map to；
如第三列的坐标名称存在，但是参数与第一列不同，则名称显示为红色，关系
自动改为 AutoName；这种情况下用户可强行指定关系为 Map to（危险操作，
会改动所有加载数据的坐标系统，除非有特殊需求的）；
如第三列的坐标名称不存在，则显示蓝色，关系自动修改为 Create；这种情况
下用户可强行指定关系为 AutoName；
2、 第二部分为第一部分表格中选中行的第一列名称对应的坐标系统参数内容；
3、 第三部分为第一部分表格中选中行的第三列名称在库中的坐标系统参数，如库
中没有第三列指定的坐标名称，则仅显示坐标参数标题；
Step 3 弹出进度条，进入数据批量输入阶段；
注：
A、 项目、工区坐标系统默认是始终更新，所有建议批量导入的项目为全新项
目；
B、 同名称数据存在时，井信息数据默认更新，其他数据默认跳过；
