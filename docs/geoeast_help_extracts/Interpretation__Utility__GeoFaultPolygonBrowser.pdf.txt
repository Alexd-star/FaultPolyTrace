断层多边形浏览与编辑
1 综述
GeoEast 数据浏览与编辑是一个在显示方式上以电子表格为主、其他方式为辅，以浏览、
编辑各种数据为主要功能的模块体系。在各个应用子系统中存在大量的数据流，它们按不同
子系统的要求以各种图形方式呈现给用户进行处理、加工。这在拥有形象、直观的优势的同
时，往往缺乏更为直接、精确的数据查看和修改手段。数据浏览与编辑正是要在这方面为用
户提供一个快捷的解决方案。由于是直接操作数据值，这种方式较之图形化的编辑精确度更
高。
2 主要功能
浏览当前项目下的所有断层多边形集合数据，新建断层多边形集合或断层多边形，对断
层多边形数据进行编辑、预览，对断层多边形集合进行复制、重命名、删除。
3 启动
3.1 启动前的准备工作
项目中已创建或加载好断层多边形数据。
3.2 启动方式
本模块可以通过在主控 Combind Fault Polygons 节点右键菜单中的 Properties...启动。

Edit 菜单包括 7 个菜单子项，前四项子菜单的功能分别在断层多边形集合编辑状态和断
层多边形编辑状态（以下简称集合编辑状态和多边形编辑状态，状态切换）下会有不同，各
菜单项功能如下：
Add 在集合编辑状态下用于追加一个空的断层多边形，在多
边形编辑状态下则用于在当前多边形数据表格中追加
一行。
Insert 在集合编辑状态下用于在当前多边形之前插入一个空
的断层多边形，在多边形编辑状态下用于在当前多边形
数据表格的当前行之前插入一行。
Remove 在集合编辑状态下用于从多边形集合中删除当前的多
边形，在多边形编辑状态下用于从当前多边形数据表格
中删除选中的行。
Remove All 在集合编辑状态下用于删除当前断层多边形集合中的
所有多边形数据，在多边形编辑状态下用于删除当前多
边形数据表格中的所有行。
Merge 合并断层多边形数据
Duplicate 将当前断层多边形集合复制一个备份
Rename 对当前断层多边形集合重命名
Delete 删除当前断层多边形集合
Switch

线集
