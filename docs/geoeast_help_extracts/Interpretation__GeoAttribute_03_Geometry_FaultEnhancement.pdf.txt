断层增强 
1 方法原理 
断层增强属性是增强地震属性体内局部平面特征的一种叠后属性，其目的是为了
提高相干属性对断层的刻画能力。通过适当的参数选择，可以增强不整合面及其它与
倾斜反射层平行的不连续性特征，还可以增强由最正和最负曲率体刻画的轴面。该算
法除了对断层有锐化作用外，还得到描绘断层的另外两个属性体断层倾角和断层倾角
方位角。图 1是相干体效果图，图 2是断层加强效果图。

说明： 
1.   本模块有三个输入数据：相干类（方差类）属性数据、 inline 方向的倾角数据
体、crossline 方向的倾角数据体，其中后两个数据体是以 原始地震数据作为输
入数据，利用多窗口倾角扫描处理出来的结果，并且需要使用归一化的相干数
据。 
2.   本模块不适用深度数据。

体，当用户选择了某个 Inline Dip 数据后，Crossline Dip 中由系统自动设置成与

入数据 Crossline Dip 可自动匹配时，在三个输入数据都选择完成后将自动设置
上述参数的默认值，其中 Time(ms)不可更改；如果输入的 Crossline Dip 数据
是由用户手动选择，则需要用户手动填写 Velocity(m/s)参数，在该参数填写完

6.   本模块参数选项中，Computation Window 中的 Time(ms)、Invalid Value 中的
NULL value for fault dip magnitude 和 NULL value for dip azimuth 均灰化，其
值由模块内定义，用户不可更改。 
7.   本模块 Computation Window 参数中，Inline、Crossline 中填写的均为倍数，即
半窗口长度=Inline 中填写的倍数*道间距，半窗口宽度=Crossline 中填写的倍数
*线间距。默认的倍数值均为 3 倍，范围[1,5]。
