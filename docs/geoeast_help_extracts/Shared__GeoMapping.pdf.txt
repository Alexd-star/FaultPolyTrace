GeoMapping 平面成图 
1  综述 
平面成图是解释系统重要的组成部分，对地震解释层位、速度等数据通过网格化、等值
线追踪及时深转换等模块实现数据的平面分布形态展示，最终形成彩色填充等值图等地震解
释成果图件。 
2  主要功能 
平面成图子系统是一个通用的平面成图和数据显示工具，其主要功能包括各种地震、地
质数据的网格化、等值线生成、各类数据的编辑以及数据的平面显示和 CGM 文件输出等。
平面成图系统注重模块的独立性，各类应用模块以及数据编辑模块都可以独立运行，实现其
应用功能。 
 
平面成图子系统包括以下主要功能： 
 图层的显示、编辑和管理 
 成图数据的保存与恢复 
 数据预处理 
 网格化 
 网格数据编辑 
 网格数据的平滑和运算 
 时深转换 
 二维数据空间校正 
 等值线追踪 
 等值线编辑 
 等值线的平滑和运算 
 等值线网格化 
 彩色填充等值线显示 
 成果图显示 
 圈闭图的生成 
 CGM 成图 
3 启动 
3.1  启动前的准备工作 
在启动平面成图子系统之前，需完成以下准备工作：利用项目管理功能建立项目和工区；
利用数据输入/输出功能加载测量成果、地震数据以及钻井、测井等用来进行地震解释的基
础数据；进行地震层位和断层的解释等工作。

3.2  启动方式 
平面成图子系统通过 GeoEast 系统主控启动。 
用户在 GeoEast 主控界面选择 Structural Interpretation，选择点击 Mapping 按钮，启动
平面成图子系统。 
主控数据树选择项目节点，启动平面成图，画区以当前项目范围为缺省的工作范围。 
主控数据树选择工区节点，启动平面成图，画区以当前工区范围为缺省的工作范围。

3.4  输入/输出数据 
3.4.1  输入数据 
平面成图系统的输入数据主要包括工区数据、井数据、各类层位数据、散点数据、断点
组合线数据、网格数据、等值线数据和边界数据。所有数据的输入均由主控来完成的。 
3.4.2  输出数据 
平面成图系统的输出数据主要指系统应用过程中生成的数据，包括散点数据、断点组合
线数据、网格数据、边界数据、等值线数据、成图数据、CGM 文件等。

Correction(校正 )、Facies（平面沉积相）、 Tools（工具）、 Properties（参数）、 Help
（帮助）等菜单项，其中 Correction(校正)菜单项仅在选择二维工区时才出现。 
4.2 工具条 
工具条位于菜单条的下方，主要提供菜单条中定义的功能的一系列快捷按钮，包括打开、
保存、撤销、恢复、删除、复制、缩放等通用操作以及通讯功能操作按钮。通讯功能包括鼠
标通讯、选线通讯、任意线通讯。根据需要，工具条可以关闭或打开。 
4.3 工具箱 
工具箱缺省位于主窗口中部右端，主要作用是提供方便快捷的编辑操作，在图元编辑状
态和数据编辑状态中分别对应各自的工具箱。工具箱属于可关闭 /打开的部件。当编辑某一
类数据时，将自动打开相应工具箱。 
图元编辑状态下工具箱与 Draw 菜单下的编辑操作保持一致，参见 5.4 节。 
数据编辑状态下工具箱的主要内容是断点组合线数据编辑、边界数据编辑、散点数据编
辑、网格点数据编辑、等值线数据编辑、彩色填充等值线数据编辑、圈闭图编辑、勘探部署
图编辑的编辑动作。参见 6 章数据编辑相关内容。 
4.4 状态条 
状态条位于主窗口的下端，用来显示操作提示信息、鼠标位置（大地坐标）和数据运算
的进程信息等。状态条属于可关闭的界面部件。 
4.5  工作区 
工作区位于主窗口的中心部位，主要用来进行各种数据（钻井数据、测网数据、散点数
据、断点组合数据、网格数据、等值线数据等）和各类图元的显示、编辑。 
色表位于主窗口右侧，提供各类数据显示的颜色 
4.6  显示管理树 
显示管理树位于主窗口中部左下端，主要提供快捷方便的图层管理（分组、改变显示次
序及属性、数据编辑等）并实现部分图层编辑功能。显示管理树属于可关闭的部件。

各类图层及其显示参数，并支持对散点数据、网格数据、等值线数据、等值线填充数据、圈
闭图数据等实体数据的保存功能，从而可以脱离数据库实现上述数据的显示恢复。同时，成
图数据也是等值线填充数据编辑后数据保存的途径。 
成图数据的保留和恢复功能，可以使用户避免重复工作，提高工作效率。用户在使用平
面成图系统的过程中，当对自己编辑成果图件比较满意时，可以保存为一个成图数据，以便
下次成图时调用。

一个显示数据是一个图层，一个图元也是一个图层。图层可以组合，可以调整显示顺序，可
以切换图层的显示状态。 
图层的编辑组织管理有两种方式，一种是通过显示管理树来实现，一种是直接在画区中
编辑图层。显示管理树中可以对所有类型的图层进行编辑管理，而画区中的图层编辑主要是
针对图元进行的编辑。

附录  常见问题解答(FAQ) 
1. 主控启动平面成图后，如何确定默认的显示范围？ 
答：平面成图启动后有个默认的显示范围，该显示范围由主控数据树来选择确定。在主控数
据树上选择某个项目名称（Project），然后启动 GeoMapping，则 Mapping 以该项目
（Project）下所有工区范围的最大范围为默认的显示范围；在主控数据树上直接选择某
个具体的工区（Survey），然后启动 Mapping，则 Mapping 以该工区范围为默认的显
示范围。Mapping 启动后，还可以通过 File 菜单下的 New 和 Change Canvas 功能改变
显示范围。 
 
2. 如何进入数据编辑状态? 
答：平面成图支持对散点数据、网格数据、等值线数据、断点组合线数据、等值线填充数据、
边界数据的编辑。对数据进行编辑，首先要通过 Layer 菜单中相关菜单项显示要编辑的
数据到画区中，数据显示后，在显示管理树中选择该数据，从右键弹出菜单中选择 Edit
进入编辑状态。 
 
3. 如何退出数据编辑并保存数据状态？ 
答：数据编辑结束后，在右键菜单中选择 Close Edit Mode，则弹出下图所示提示对话框： 
 
选择 Yes 保存数据到当前打开的数据文件中并退出编辑状态，No 放弃对数据的修改并
退出编辑状态，Cancel 放弃退出操作，回到数据编辑状态。用户也可以先选择 File 菜
单或编辑右键菜单中的 Save 或 Save As 菜单项保存数据。只有退出数据编辑状态，才
能恢复数据编辑状态下暂时灰化屏蔽的操作。 
 
4. 如何在平面成图中显示外部加载的各类数据？ 
答：平面成图作为一个通用的平面数据成图平台，支持外系统数据的显示和成图，包括外部
散点数据、网格数据、等值线数据。同时，平面成图提供方法解决外部数据无确定显示
范围而导致的无法在画区中快速定位显示数据的问题，方法如下： 
1）通过 IO 正确加载外部数据（方法详见 IO 用户手册）。 
2）选择 File 菜单项中的 Change Canvas 菜单项，在弹出对话框中选择 Extents Type，
根据外部数据的不同，分别选择 From Scatters、From Grids、From Contours 项，
然后点击 Set 选择需要显示的外部数据，确定后，改变画区显示范围以适合显示外
部数据。 
3）选择 Layer 菜单加载相应的外部数据即可。 
 
5. 如何实现完美的等值线填充效果？ 
答：平面成图中要达到好的等值线填充效果需要一定的应用技巧。等值线填充效果的好坏关
键在于等值线填充边界的计算，复杂数据的情况下边界计算可能会有误差导致填充效果

不好，此时可以通过用户自定义边界的方式解决，方法如下： 
1）通过 Edit 菜单中的 Create Boundary 功能手工拾取一个精确边界。 
2）网格化时选择该边界数据进行网格化。 
3）等值线追踪时选择该边界数据追踪等值线。 
4）等值线填充时，在 Properties 中选择该边界数据以限制等值线的填充显示。 
经过以上操作，可以达到尽可能好的等值线填充效果。 
在某些情况下，含断层组合线的等值线填充出现大面积填充错误，首先怀疑断层组合线
是否有重合，删除重合的断层组合线重新填充，可就以达到理想的等值线填充效果。 
 
6. 如何实现逆断层叠合成图？ 
答：成图中采用了分块网格化、等值线追踪的的方法，通过图层显示的软件技术实现逆断层
叠合成图。采用独立定义、分片存储的方式记录一个应用上定义的多值层；在数据管理
上采用单独定义、管理多个层位的办法实现多值层解释。即根据逆断层的上盘、下盘分
片存储层位数据。属于一个应用多值层的多个对立层位通过交互的操作功能各自定义边
界，然后分别对逆断层的上盘、下盘数据进行网格化和等值线追踪。充分利用图层的显
示特点，联合多个相互关联的层位产生成果图样。主要通过多边形逆掩区域（沿层位重
叠趋势拾取的多边形即边界数据）来实现等值线的限制显示。通过显示参数控制实现各
种显示风格的逆断层叠合成图。多边形逆掩区域内外的等值线、断点组合线可以分别以
不同的显示形态表示。 
 
7. 如何理解各类显示数据的默认显示参数和当前显示参数？ 
答：成图中数据的显示参数包括当前参数和默认参数两类，当前参数只对当前显示的数据起
作用，可以在显示管理树选择数据后的右键菜单的 Properties 项中设置更改，加载图层
时也可以通过 Properties 设置当前图层的显示参数；默认参数为各类数据的默认显示属
性，在 Properties 的下拉菜单中进行的各类数据参数设置均设置为默认参数，默认参数
保存到 mappingrc 文件中，下次启动 Mapping 时仍然起作用。 
 
8. 如何建立以及实现平面成图中中文输入环境？ 
答：成图支持中文输入和显示，中文输入法使用 Linux 自带的中文输入法。要确定操作的
Linux 环境支持中文的显示和输入。 
平面成图中有三处地方支持中文的输入，一是图元编辑中支持添加中文文本；二是责任
表内容设置中支持中文的输入；三是图例内容设置中支持中文的输入。 
 
9. 如何理解平面成图状态保留与状态恢复功能？ 
答：成图中提供的状态保留和恢复功能，主要是为了避免用户的重复工作，提高工作效率。
用户在使用平面成图的图层编辑过程中，对自己编辑成果图件比较满意时或者编辑过程
中临时退出，可以将该状态保存，以便下次调用，直接恢复图层编辑场景。
