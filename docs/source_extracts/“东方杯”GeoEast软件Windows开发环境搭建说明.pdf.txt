GeoEast 软件Windows 开发环境搭建说明 
本文档意在说明使用GeoEast-RC 开发组件进行开发前所需安装的软件，主要包括
Visual Studio 2019、qt-vsaddin、GeoEast-RC.Develop 以及GeoEast 数据包等。 
需要注意： 
 
安装路径不要包含中文、空格或特殊字符 
 
计算机用户名不可包含中文字符或特殊符号 
 
部分软件安装需要管理员权限 
 
数据包解压目录和软件安装目录最好分离 
 
如GeoEast-RC 安装后启动geoeast 报错，请重启计算机后再打开 
 
 
【注：VS2019、qt-vsaddin 这些第三方软件，也可以从大赛提供的网盘资料中下载】

3 常见问题 
安装完成后，桌面会出现geoeast 图标，双击能够启动geoeast 主控界面，如果不能启
动，或者之后的其他功能模块有问题，可能的原因如下： 
1）安装本产品务必使用英文用户名，用户名只能由标准字母和数字构成。中文用户名会导
致GeoEastRC 无法正常使用，含有特殊字符的用户名会出现不确定问题。 


===== PAGE 15 =====
2）安装本产品选择的数据模型解压目录和GeoEastRC 主运行目录务必选择纯英文目录，且
目录间不要有空格。 
3 ）安装后运行，部分用户会出现缺少
vcruntime140d.dll
情况，安
装%NGP%/support/PostgreSQL/product/installer/vcredist_x64.exe 即可 
4）安装账号需要有管理员权限，同时要确定选择安装的数据目录，本账号有完全读写权限。 
5）如果机器安装了安全客户端（防病毒软件），安装过程中会有安全提示，请选择允许。建
议安装时先停止安全工具，保证安装过程的顺利。 
6) 安装完成后，如果启动
geoeast
闪退，请手动执行安装目录下的
EnvironmentSetting\EnvironmentSetting.exe 程序。

五 Python 环境 
GeoEast 软件使用一套基于miniconda3 的Python 虚拟环境，环境内所安装的第三方库
及其版本是根据已集成的模块而定，该minidaon3 目录单独以压缩包的形式提供，大家下载
后解压放置在GeoEast-RC 安装目录如下位置：%NGP%/support/miniconda3。 
赛题尽可能的使用miniconda3/envs/nv 这套虚拟环境完成，如果确实需要追加安装新
的第三方库，可自行在环境内安装，提交作品时将新安装库及版本附requirement.txt 文件说
明。 
在Python 程序的集成方面，iEco 平台提供了Python 数据接口库“PyBO”和C++调用
Python 框架库“PyCaller”，详细的配置、使用可以参考培训课程视频相关的内容。
