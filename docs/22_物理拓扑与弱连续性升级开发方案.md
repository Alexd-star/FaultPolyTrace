# FaultPolyTrace 物理拓扑与弱连续性升级开发方案

## 1. 目标与边界

本轮工作面向二维平面断层属性到闭合断层多边形的追踪质量、泛化能力和工程可靠性。开发遵循“冻结基线、影子运行、量化比较、失败回退、逐项晋级”的原则，不把尚未验证的新算法直接替换正式流程。

历史回退线为214个保留多边形，当前正式默认线为200个保留多边形。两套结果的源码提交、输入数据哈希、CSV哈希和GeoEast回读哈希记录在`tests/baselines/official_release_baselines.json`。新增模块关闭时，正式输出必须保持200基线不变。

本轮不扩展到三维解释，不引入依赖标注训练的上游模型，不以多边形数量作为优化目标。判断标准是断层形态连续性、对象归属、背景隔离、边界质量、完整几何有效性、确定性、性能和GeoEast读写一致性。

## 2. 已有能力与复用策略

项目已有多尺度分支方向、交点聚类、属性/宽度/背景联合代价和精确匹配，因此`BranchAttribution`继续作为分支归属求解器。新建的`SkeletonGraphV2`负责把像元交点簇提升为拓扑节点，并提供端口、半边和分支身份；不重复实现另一套分支配对器。

项目已有受限弱路径、弱尾链、局部多边形质量、覆盖保护和事务式GeoEast写入。升级工作通过扩展这些接口完成，不在正式主流程中增加数据集专用坐标、固定多边形编号或隐式补丁。

### 2.1 当前核心模块边界

本轮将原先集中在`FaultTracer.cpp`中的参数契约、候选矢量化、结果后处理和质量计算拆分为可独立测试的模块。当前核心职责如下：

| 模块 | 单一职责 |
|---|---|
| `TraceOptions.h`、`TraceResult.h` | 追踪输入参数和输出数据契约 |
| `TraceOptionsValidation.*` | 参数有限性、范围、组合关系和资源预算校验 |
| `TraceOptionAdapters.*` | 将产品级参数转换为各子算法参数，避免重复赋值 |
| `FaultTracer.cpp` | 组织算法阶段、计时和失败回退，不再承载全部实现细节 |
| `SkeletonGraph.*`、`SkeletonGraphV2.*` | 像元骨架图与交点簇拓扑图 |
| `BranchAttribution.*` | 分支方向证据、候选配对和精确归属分析 |
| `WeakContinuityConnector.*`、`WeakTailRestorer.*` | 受限弱路径和端点弱尾恢复 |
| `FinalBridgeGate.*` | 弱连接对象归属、内环、包络和最终拓扑事务门控 |
| `PolygonVectorizer.*` | 掩膜到闭合外环/内环、多边形筛选和覆盖保护 |
| `PolygonQualityMetrics.*` | 共享保守栅格化、强弱支撑、泄漏和边界质量统计 |
| `AdaptiveBoundary.*` | 默认关闭的局部自适应边界候选、证据和批量提交 |
| `TracePostProcessor.*`、`Topology.*` | 几何后处理和完整几何合法性门控 |
| `DiagnosticsIO.*` | 机器可读诊断、阶段耗时和候选复核数据输出 |

拆分后，`FaultTracer.cpp`由约4650行降至约2420行。新增模块同时列入CLI构建脚本、C++测试、AddressSanitizer构建、GeoEast qmake工程和Visual Studio工程，独立软件与GeoEast插件继续复用同一核心实现。

## 3. 实施顺序

### 3.1 数值安全与诊断真实性

1. 非有限属性不得被归一化为高支撑。
2. 局部背景分位数只使用有限样本；没有有限样本时返回显式无效状态。
3. 路径支撑统计排除两端已有强骨架，避免短路径被端点虚高。
4. 诊断记录接受前后的候选总数、无效属性数量、背景样本数量和实际评价像元数量。

### 3.2 完整几何门控

内部检查覆盖重复点、零长度边、零面积环、环自交、孔洞越界、孔洞互含、孔洞错误接触、多边形面积重叠和完整包含。发布验证脚本通过Shapely调用GEOS进行独立交叉校验，正式C++核心不因此增加运行时依赖；缺少该验证环境时，核心内部检查仍可独立运行。几何合法性只作为底线，不替代断层对象归属判断。

### 3.3 物理度量与形态学

统一`GridMetric`负责网格索引、世界坐标、物理距离、方向和像元/物理半径换算。现有像元参数继续保留兼容语义；新影子模块使用世界坐标椭圆结构元：

```text
(offsetX * dx)^2 + (offsetY * dy)^2 <= radiusWorld^2
```

正式数据`dx=dy=10 m`时，物理距离模块不得改变等间距方向判断。方形结构元与椭圆结构元的差异单独输出，不直接晋级。

### 3.4 SkeletonGraphV2

1. 识别度数不等于2的像元并收缩相邻交点簇。
2. 每个交点簇建立中心、成员像元和外连端口。
3. 每条分支表示为一对半边，记录起止节点、端口、路径和物理长度。
4. 闭环分量使用显式环节点表示。
5. 输出与旧图的端点数、交点像元数、交点簇数、分支数和连通分量差异。

### 3.5 弱扩展与弱尾链

弱响应连通块不再仅按`sizeOk || shapeOk`判断。候选门控按小组件和大组件分层，统一检查种子接触、有限属性支撑、物理线性、宽度稳定、端口归属和竞争分支。新规则先以影子统计运行。

弱尾链必须真实接触唯一端点端口，恢复后与所有者严格连通，并避开交点簇邻域。整连通组件标签只作为候选检索，不再作为最终归属依据。

### 3.6 弱连续性全局决策

候选生成使用端口物理切线、物理距离、局部宽度和属性支撑。路径代价使用物理步长、方向状态、曲率变化、背景对比和第三方对象净空。候选选择使用带“不连接”选项的全局最小费用匹配；存在空间冲突时再对局部小规模候选执行精确互斥求解。

完整Finsler fast marching保留为后续可替换搜索后端，不作为本轮默认依赖。当前实现先提高方向状态和物理代价的一致性，保证可测试、可回退和可在GeoEast插件中部署。

### 3.7 多尺度辅助证据与自适应边界

原始断层属性始终是主证据。当前实现采用物理尺度一致的Hessian风格有限差分响应，仅提供辅助方向、局部尺度和置信度；它不是完整Steger亚像元定位器，也不替代原属性。低置信度或与原属性冲突时自动回退。后续如引入亚像元中心或等值线，只能作为可替换候选后端，并继续通过覆盖、背景泄漏、拓扑和稳定性门控。

## 4. 晋级条件

每个候选模块至少满足：

1. 功能关闭时正式基线哈希不变。
2. 开放环、自相交、孔洞错误、面积重叠和完整包含均为0。
3. 强响应覆盖不下降，弱响应变化有逐对象解释。
4. 背景泄漏不增加，或增加量有明确人工认可和形态依据。
5. 不增加高风险误合并和无支撑短桥。
6. 参数小扰动下对象、中心线和边界保持稳定。
7. 全图、叠加图、24分块和全部变化局部图完成人工复核。
8. CLI、独立软件、GeoEast插件结果一致，GeoEast写入后可回读。
9. 性能和内存仍满足赛题要求，异常输入不会造成卡死或无限运行。

任何一项失败，模块保持影子或复核层，不进入默认结果。

## 5. 参数与产品界面

核心算法参数、CLI帮助、GUI预设和GeoEast调用必须由单一参数定义源生成或校验。普通用户只看到追踪模式、业务预设、主阈值/分位数、最小面积和少量显示设置；研究参数保留在高级实验配置和诊断文件中。自动推荐只表述为带置信度和适用范围的初始建议，不表述为全局最优。

## 6. 验收输出

每轮候选实验输出机器可读指标、候选级理由、基线/候选差异、多边形与中心线全图、原属性叠加图、24分块图、全部变化局部图、耗时、峰值内存、确定性哈希和GeoEast回读结果。只有通过门控的代码进入统一构建和交付包。

## 7. 当前实施结果

### 7.1 稳定基础设施

以下能力已经进入统一核心，并在候选功能关闭时保持结果兼容：非有限值防护、完整内部拓扑检查、GEOS交叉验证、统一物理度量、物理椭圆结构元、交点簇图、分层弱扩展诊断、端点端口弱尾诊断、物理弱路径、不连接代价匹配、多尺度Hessian风格辅助证据、最终对象桥接门控、共享多边形栅格质量计算和自适应边界候选层。

正式数据默认运行仍输出200个保留多边形。支撑包络与作用域弱桥晋级后的CSV SHA256为`EE7473CD04A3EA988166DD4502EEE70D4FB4A0D674135541A9B38490C3B91369`；关闭局部防黏连可复现v1.1.2结果`3DE2427DF3E136A33396EAAAF512A83AC2AE3A0CACB3976AA52F3804A4056DCC`，关闭简单环兼容可继续回退到`2911D696F880E1173F6633E6B8A4587316FDC7DFA19109CE8EB28083A076ED3A`。内部检查和Shapely/GEOS交叉验证均判定几何有效，开放环、自交、内环、完整包含和内部面积重叠均为0。

### 7.2 图与弱连续性候选

`SkeletonGraphV2`将12946个原始交点像元收缩为1140个交点簇，生成1458条分支、2916个端口和2916条半边。当前仍有335个端口邻接歧义，因此V2只进行归属A/B诊断，不接管默认骨架分组。

分层弱扩展在400个弱连通组件中接纳48个，而旧规则接纳283个；其中351个组件因多所有者竞争被拒绝，说明现有所有者定义过于保守。严格端点端口弱尾层由旧规则的24个接纳候选收敛为15个。两者均保留为影子诊断，避免未经证实的弱断层删减。

物理弱路径与全局不连接匹配在正式影子运行中形成17个冲突分量，17个均由精确求解器处理，无复杂度回退，最终接受13条连接。当前求解器已经处理端点互斥和“不连接”选择，但尚未把所有候选路径之间的空间交叉、重叠和复合分支身份编码成完整全局优化问题；第三方骨架净空和`FinalBridgeGate`仍作为发布前安全门控。

### 7.3 自适应边界候选

自适应边界只在局部候选内移动边界顶点，使用原属性强弱支撑、多尺度辅助置信度、背景泄漏、粗糙度、面积变化和完整拓扑进行事务门控。本轮200个对象中39个候选通过并提交，数量、对象身份和内环数量保持不变。候选CSV SHA256为`A8DDEB7AEA3F97AE9D6E2685994ABA3E9DD22D342CCEC99C64BA873FB1A4AB80`。

相对200基线，候选的强响应覆盖率提高0.014012个百分点，弱响应覆盖率提高0.010849个百分点，背景泄漏代理比例下降0.241504个百分点，多边形内无支撑比例下降0.201818个百分点，低支撑桥像元减少10个，完整拓扑仍为0问题。几何A/B总IoU约为99.5087%，未出现对象拆分或合并。自动门控已通过，但这些指标没有使用专家地质真值，仍不能单独证明39处调整全部符合最终解释意图，因此该能力保持默认关闭。

人工复核包位于`outputs/evidence/adaptive_boundary_ab_review_20260801`，包含高清全图、属性覆盖差异图、24幅全图分块、39幅全部变化对象局部A/B图和机器可读清单。

### 7.4 性能、稳定性与构建

最终桥接门控改为增量组件所有权索引、并查集合并、孔洞缓存和局部事务提交；分支交点聚类改为确定性空间哈希；基础骨架图改为定长邻域、扁平节点类型和扁平边访问表；多边形质量计算复用行扫描保守栅格器。正式数据默认总耗时由约2.77 s降至约1.37 s，核心追踪由约1.90 s降至约0.51 s，最终弱连接门控上下文构建由约942 ms降至约34 ms。开启自适应边界候选的总耗时由约29 s降至约2.09 s，候选结果哈希保持不变。

当前支撑包络版本连续运行10次，全部得到正式结果哈希：总耗时P50/P95为1762/1815 ms，核心追踪P95为936 ms，最大工作集约48.62 MiB，工作集与句柄趋势未见超门限增长。AddressSanitizer已完成候选路径和异常输入验证且未报告内存安全错误；Application Verifier Basics已在管理员权限下完成最终二进制复核，日志条目为0。该结论覆盖已执行的CLI路径，不等同于形式化证明不存在任何泄漏。

全部C++核心回归和237项Python测试通过；CLI、独立软件、GeoEast BO runner、GeoEast启动器及主框架插件均已重新构建，独立软件216项界面契约和GeoEast插件135项界面契约通过。qmake与Visual Studio工程清单均已包含本轮新增模块。

### 7.5 GeoEast简单环兼容

GeoEast `BOFaultPolygon`将每个`Segment`解释为一个普通闭合断层多边形，SDK字段中没有外环、内环及父环角色。此前200结果中的`polygon 122`由一条17像元弱尾链闭合形成1个面积266400 m²的内环；独立软件可按WKT孔洞显示，但DAT和BO对象只能保留外环，因而在GeoEast中会将该空白区错误填充。

最终实现分为两层。弱尾拓扑门控可在不启用最终兼容层时，从候选自由端逐格回退并复用正式断层带构造器验证，避免整条尾链全部撤销。产品默认采用覆盖更完整的最终简单环兼容层：面积不超过25个像元的小孔仅在不会合并不同对象时填补；较大背景环使用属性加权最短路寻找最窄出口，开槽后必须减少内环且不得增加活动对象数量。规则只依赖掩膜拓扑、属性支撑和通用资源上限，不读取固定多边形编号或坐标。

官方数据共有9个内环。最终兼容层填补6个小孔，共32个像元；另外3个背景环仅移除6个无属性支撑的断层带包络像元。多边形数量保持200，强响应覆盖率保持99.855208%，弱响应覆盖率保持97.651143%。老师反馈对象的变化面积由整段回退方案的5200 m²收敛到300 m²，弱属性轨迹基本保留。全部内环消除后，局部形态复核候选减少4个，高优先级候选由3个降为0，完整拓扑和GEOS检查仍为0问题。

最新GeoEast BO runner已在`BGPCup2026_Test7`工区以独立对象名完成事务式写入和逐点回读：200个闭合外环、62420个顶点，源内环数为0，预期与实际几何哈希均为`050602F47C5FA336`，拓扑、样式和存储检查通过。Qt正式导出器生成62620行闭合坐标，未省略任何内环，DAT SHA256为`93A5B6441734762F111517AA555372C44B850B51DD295345EBD5FD460C5F4CDC`。

### 7.6 相邻脉络拆分与稀疏端点补连

局部复核发现一类组合问题：同一结果对象先将两条近邻脉络包入同一断层带，随后真正应延续的上方脉络又因骨架端帽内缩而未进入最终补连候选。该位置的多边形边界间隔约88 m，而骨架端点间隔约156 m；仅提高最大连接距离会同时放大其他交切位置的误连风险。

实现已拆分为`SupportEnvelopeSeparator`和`ScopedWeakBridgePolicy`两个独立模块。前者以原属性为主证据，在物理圆形邻域内构造支撑包络；仅当观测支撑恰好包含两个分量、移除单元属于低值背景、移除比例受限、不损失保护路径、结果恰好形成两个达到面积、比例和物理线性要求的有效部分时提交拆分。后者只在已提交拆分的局部影响范围内启用端帽宽度修正距离和一像元稀疏邻域支撑；凡使用扩展距离或邻域替代支撑的候选都必须通过该作用域检查，旁侧已有骨架也不能向当前路径借用支撑。

多形态测试覆盖水平与斜向近邻脉络、宽断层带、Y形分支、独立交叉、三分支、紧凑斑块、弱桥、小噪声、受保护弱路径和非方形采样。80套八类独立平面案例及12套1501×701复杂同域网络均与关闭模块的历史基线逐文件一致，对象误合并、过分割、漏检和拓扑指标未发生变化。验证过程中曾发现邻域支撑在未提交拆分时全局生效并导致1个额外拆分，该问题已通过统一作用域门控修复并加入回归测试。

官方数据候选仍保留200个多边形，仅新增1条最终对象连接。该连接两端中心线夹角误差分别约6.55°和4.76°，原路径支撑率为100%，相邻竞争候选因曲率突变被拒绝。候选CSV SHA256为`EE7473CD04A3EA988166DD4502EEE70D4FB4A0D674135541A9B38490C3B91369`，三次独立运行一致。相对正式简单环200基线，强响应覆盖率不变，弱响应覆盖率提高0.032548个百分点，局部形态候选减少1个，背景泄漏代理比例下降0.019238个百分点，低支撑桥像元减少20个；完整拓扑和GEOS检查均通过。
