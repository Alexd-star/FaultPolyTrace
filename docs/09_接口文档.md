# 第9章 接口文档

## 9.1 接口范围

当前项目不提供 HTTP REST API。项目接口主要包括命令行接口、GeoEast BO runner 命令接口、输入输出文件格式和 GUI 对执行程序的参数转发。本文根据当前代码和脚本推断接口用途，具体新增参数应以 `faultpolytrace.exe --help` 和源码解析为准。

## 9.2 核心命令行接口

核心入口：

```text
bin/faultpolytrace.exe
```

常用参数包括：

| 参数 | 说明 |
|---|---|
| `--input` | 输入网格文件路径。 |
| `--input-format` | 输入格式，可为 `auto`、`geoeast-dat` 等。 |
| `--output` | 输出多边形 CSV 路径。 |
| `--diagnostics` | 输出诊断 JSON 路径。 |
| `--branches-output` | 输出骨架分支 CSV。 |
| `--topology-output` | 输出拓扑诊断 CSV。 |
| `--trace-mode` | 追踪模式，常用 `ridge-belt`。 |
| `--threshold-mode` | 阈值模式，常用 `percentile`。 |
| `--percentile` | 百分位阈值。 |
| `--min-area` | 面积过滤阈值。 |
| `--belt-radius` | 断层带包络半径。 |
| `--simplify-tolerance` | 边界简化容差。 |
| `--smooth-iterations` | 边界平滑次数。 |

## 9.3 GeoEast BO runner 接口

GeoEast runner 入口：

```text
geoeast_plugin/bo_runner/faultpolytrace_geoeast_runner.exe
```

典型参数包括数据库、项目、用户、输入网格、输出多边形和算法参数。它的职责不是展示界面，而是在 GeoEast 环境中完成读取、写入、删除、导出和预览数据。若缺少 GeoEast SDK、license 或数据库配置，runner 可能无法独立运行。

## 9.4 输出文件接口

主要输出包括：

| 文件 | 说明 |
|---|---|
| 多边形 CSV | 保存多边形编号、面积、周长、状态、坐标或 WKT 信息。 |
| 诊断 JSON | 保存参数、耗时、覆盖率、拓扑统计和运行摘要。 |
| 分支 CSV | 保存骨架分支信息，用于调试和质量分析。 |
| 拓扑 CSV | 保存自相交、异常相交等诊断细节。 |
| PNG 图件 | 由质量评估脚本生成，用于人工复核和答辩展示。 |

## 9.5 GUI 调用关系

独立软件和 GeoEast 启动器通过参数构造调用核心执行程序或 BO runner。GUI 应负责前置检查，例如输入文件是否存在、输出目录是否可写、数据库配置是否完整、结果对象是否选择；执行程序负责返回明确日志和错误信息。
