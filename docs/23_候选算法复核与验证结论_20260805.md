# 候选算法复核与验证结论

核验日期：2026-08-05  
当前正式版本：`v1.1.3`  
当前正式结果：200 个保留多边形

## 1. 结论摘要

当前正式结果继续采用 `v1.1.3` 的 200 个闭合多边形。它在官方数据上的正式覆盖、完整拓扑、GeoEast 外环语义和处理速度已经形成稳定交付基线；本轮没有发现一个能够在独立同域数据、复杂同域网络和官方结果三层同时证明“明显提高质量且不增加误合并”的候选算法，因此不替换正式结果。

本轮最重要的工程修正是统一验证口径。旧的复杂同域脚本显式关闭了当前产品已经启用的局部防黏连机制，得到的是历史验证线，不能直接用于评价当前软件。现在脚本同时保留两种明确的基准配置：`current_product` 用于反映新打开 CLI、独立软件和 GeoEast 插件的产品默认行为；`historical_214` 仅用于复现早期 214 结果的历史记录。默认验证配置已改为 `current_product`。

## 2. 正式结果与残余问题

官方数据的正式结果为 212 个候选、200 个保留多边形，强响应覆盖率约 99.855%，弱响应覆盖率约 97.684%，开放环、自交、边界冲突、完整包含和内部面积重叠均为 0。正式输出已通过 GeoEast 简单外环兼容处理，因此不依赖 GeoEast 对内环角色的支持。

当前残余未覆盖不能简单解释为“阈值过高”。复核层将其分成四类：

| 类型 | 现象 | 当前处理 | 是否适合自动写入正式层 |
|---|---|---|---|
| 数据边界截断 | 强或弱响应贴在网格边界，真实延伸方向超出观测范围 | 标为边界复核，不向边界外推 | 否 |
| 局部包络不足 | 弱响应位于主断层附近，两侧已有结果对象，但局部包络未覆盖 | 生成局部补包络候选，检查所有者和拓扑 | 只有逐图复核后才考虑 |
| 端点微缺口 | 两端方向和宽度相近，缺少短距离端帽或局部弱像元 | 生成受限端点候选，检查竞争分支、内环和第三方对象 | 当前默认不自动写入 |
| 游离弱线性残余 | 形态近似断层，但距离正式对象较远或所有者不唯一 | 写入复核层，不写入正式多边形 | 否 |

因此，正确目标是“在不产生明显误合并的前提下保持方向连续和弱属性支撑”，而不是取消阈值或接收全部深色像元。一个弱像元与已有响应相连，只能说明属性空间存在邻接关系，不能单独证明它属于同一断层对象。

## 3. 候选算法 A/B 结果

### 3.1 官方规模复杂同域网络

使用 12 套 `1501×701` 的独立复杂平面属性案例。每个案例先生成 26 个几何真值对象，再渲染稀疏属性和相关背景；生成器不读取官方坐标、对象编号或输出多边形。

| 候选 | 结果 | 结论 |
|---|---|---|
| 物理度量 + 全局匹配 | 191 个保留多边形，损失 9 个结果对象 | 拒绝；路径更严格但没有形成可接受的质量收益 |
| 严格残余追踪 | 205 个多边形，覆盖提高 | 拒绝；必须关闭核心防黏连保护，风险不可接受 |
| 自适应边界修形 | 12 例中 4 例发生变化；拓扑、误合并、过分割和漏对象指标均未恶化 | 安全但收益很小，保持候选层 |
| 端点内环延后判定试验 | 12 例输出与当前产品完全一致 | 没有证明收益，不增加新的产品开关 |

自适应边界修形的平均像元 IoU 变化约为 `+0.00000084`，平均 Boundary F1 变化约为 `+0.00000185`，平均中心线走廊 F1 变化约为 `+0.00000588`，属于远低于晋级阈值的微小变化；因此不能用“通过安全门控”表述为“已经证明更正确”。

### 3.2 80 套独立同域平面案例

80 套案例覆盖孤立曲线、近邻平行、分支、独立交叉、弱缺口、变宽断层带、边界截断和噪声背景。当前产品默认的平均像元 IoU 为约 0.878，平均 Recall 为约 0.957，中心线覆盖为 1.0，非法多边形和异常相交均为 0。自适应边界候选在 80 套案例上与当前产品结果逐文件一致，说明它没有在简单规则图形上产生无依据的扩张或收缩。

增益 `0.85/1.15`、高斯噪声 `0.02` 和轻平滑 `sigma=0.70` 的 320 次扰动也已纳入 A/B 门控。当前产品与自适应边界候选的全体最差 IoU 均为约 0.7981，逐案例最差 IoU 的平均值均为约 0.9172，全部扰动 IoU 的平均值均为约 0.9573；候选没有降低稳定性，但也没有产生可测的稳定性收益。

这一结果的意义是“没有观察到副作用”，不是“已经证明跨真实工区泛化”。这些案例是具有独立真值的可控同域数据，不能替代专家解释的真实工区。

## 4. 为什么不继续降低阈值

降低强响应或弱响应阈值会同时带来三种变化：

1. 原本属于相邻断层的弱带更容易进入同一连通分量；
2. 骨架交点、端点和分支数显著增加，后续归属问题变得更难；
3. 多边形面积和桥接区域增加，但覆盖率上升不等于解释质量上升。

当前算法已经把“弱响应发现”和“正式对象接收”分开：弱响应可以进入质量地图、残余复核层和候选路径分析；正式层还必须经过端点方向、局部宽度、竞争分支、第三方对象净空、内环变化和完整拓扑门控。这个分层是比全局降阈值更适合生产使用的做法。

## 5. 仍值得保留的算法方向

### 5.1 端口级弱连续性

下一阶段若获得专家对局部候选的确认，应继续强化端点端口而不是扩大连通域：以端点切线、物理距离、局部宽度和属性支撑生成候选路径，加入“不连接”选项，并在局部冲突图中进行全局互斥选择。当前实现已有这些模块的影子和门控，但复杂网络中仍存在端口归属歧义，不能直接接管正式分组。

### 5.2 多尺度方向和宽度作为辅助证据

Steger 的曲线结构检测明确把线的位置和宽度作为可估计量，并讨论了非对称线型造成的定位偏差；这支持“属性为主、多尺度方向和宽度为辅”的路线，而不支持用单一 Hessian 响应替换原始断层属性。参考：[Steger, An Unbiased Detector of Curvilinear Structures](https://mv.in.tum.de/_media/members/steger/publications/1996/fgbv-96-03-steger.pdf)。

### 5.3 方向提升的曲率路径

带方向状态的 Euler–Mumford/Finsler 路径可以在位置—方向空间中表达曲率约束，比普通 8 邻域最短路更适合弱连续结构。但它的工程代价和参数校准成本更高，应先在候选后端中实现，与当前离散 A* 做逐案 A/B，不直接替换默认搜索。参考：[Chen, Mirebeau and Cohen, Global Minimum for a Finsler Elastica Minimal Path Approach](https://arxiv.org/abs/1612.00343)。

### 5.4 几何底线

GEOS 官方 C API 提供稳定的 C API/ABI、`GEOSisValid` 和拓扑保持简化接口；其有效性规则覆盖环自交、内环包含关系以及多多边形组件的接触或重叠。项目继续使用自身 C++ 拓扑检查作为运行时底线，并用 GEOS 交叉验证发布结果，不把几何有效误写成地质对象归属正确。参考：[GEOS C API](https://libgeos.org/usage/c_api/)、[GEOS C API 文档](https://libgeos.org/doxygen/geos__c_8h.html)。

## 6. 当前发布决策

1. `v1.1.3 / 200` 继续作为 CLI、独立软件和 GeoEast 插件的统一默认结果。
2. 自适应边界修形保留为实验/复核能力，不进入默认参数，不替换正式 DAT。
3. 物理度量、全局匹配、分层弱扩展、严格端点弱尾和 SkeletonGraphV2 继续保持影子或候选状态。
4. 质量检查器和残余复核层可以作为产品质检能力保留，但复核候选与正式多边形必须在界面和输出文件中分层显示。
5. 只有当候选在当前产品默认基准、独立同域真值基准、复杂同域网络、参数扰动和 GeoEast 回读五个层面同时通过门控，才允许晋级并重新构建交付包。
