# 第2章 用户手册

## 2.1 使用前说明

FaultPolyTrace 提供两种主要使用方式：独立软件方式和 GeoEast 集成方式。独立软件适合直接打开外部网格文件并查看结果；GeoEast 集成方式适合在 GeoEast 工区中选择已有 `BOMapGrid`，运行后把结果写回为 `BOFaultPolygon`。用户不需要理解全部算法细节，但需要知道输入数据代表的是断层属性强弱，输出结果代表闭合断层多边形。

正式使用前建议先阅读发布包中的 `README_先打开我.md`，然后打开独立软件或 GeoEast 菜单入口。若只是快速验证软件是否能运行，可使用发布包根目录的 `02_运行离线演示.cmd`。若要完成赛题官方数据验证，应以官方 `test.dat` 或 GeoEast 中对应导入后的 `test7_fault_attribute_bo` 为输入。

## 2.2 独立软件基本流程

独立软件推荐入口为：

```text
release/FaultPolyTrace_v1.0.1-contest-final/FaultPolyTrace.exe
```

基本操作流程如下：

1. 打开 `FaultPolyTrace.exe`。
2. 在数据源区域选择“外部文件”。
3. 点击【选择输入文件】，选择 DAT、ASCII 或矩阵文本文件。
4. 设置输出目录和输出名称。
5. 根据需要选择追踪预设、面积阈值、显示颜色和图层显示状态。
6. 点击【开始追踪】。
7. 运行完成后查看耗时、日志、原始网格层、结果多边形层和叠加图层。
8. 如需复查结果，可在历史记录或输出目录中重新选择已有 CSV 结果。

如果用户刚选择输入文件但还没有运行追踪，软件应只显示原始网格，不应让用户误以为已经生成结果。结果图层只有在运行成功或选择已有结果后才应显示。

独立软件的【文件】菜单提供参数模板保存、参数模板打开和运行日志保存。参数模板采用 JSON 文件，只保存算法参数和质量模式，不改变输入文件、输出目录或数据库连接；载入时会检查模板版本、字段类型和取值范围。需要向同组成员说明结果时，可在【编辑】菜单选择【复制当前结果摘要】，一次取得数据源、结果位置、预设、显示样式和耗时信息。

## 2.3 GeoEast 集成基本流程

GeoEast 集成方式适合已经打开工区、具备有效 license、能够访问数据库的用户。部署成功后，用户从 GeoEast 主界面菜单或按钮进入“断层多边形追踪”工具。启动器会尽可能自动识别 GeoEast 根目录、当前用户、数据库和项目；如果自动识别失败，需要在数据库配置窗口中手动设置。

基本操作流程如下：

1. 在 GeoEast 中打开目标工区。
2. 点击 FaultPolyTrace 菜单入口。
3. 在启动器中点击【刷新网格列表】。
4. 在“输入网格”下拉框中选择目标 `BOMapGrid`。
5. 设置输出多边形名称，例如 `FaultPolyTrace_Result`。
6. 选择推荐参数预设或手动调整面积阈值、带宽、平滑等参数。
7. 点击【开始追踪】。
8. 运行成功后确认日志中出现写入 `BOFaultPolygon/<输出名称>` 的提示。
9. 在 GeoEast 工区底图或平面成图中叠加查看原始网格和结果多边形。

GeoEast 启动器中的颜色、线宽和透明度用于调整当前窗口的显示效果，其中透明度不会改变 `BOFaultPolygon` 几何。参数模板可与独立软件互相读取，数据库密码不会写入模板或用户配置。运行日志和当前结果摘要可从菜单保存或复制，便于验收留档。

如果点击网格或结果下拉框没有内容，应先检查数据库配置、GeoEast license、项目名称、用户信息和 BO runner 是否可运行。详见 `docs/14_常见问题FAQ.md`。

## 2.4 参数使用建议

普通用户优先使用默认推荐参数。面积阈值用于过滤面积过小的碎片多边形，阈值越大，小碎片越少，但可能过滤掉真实小断层。平滑参数用于让边界更自然，但过度平滑可能导致边界偏离属性响应。根系防黏连用于减少相邻但不同脉络的断层被错误合并，默认主线已经启用受控防黏连策略。

当结果出现漏检时，不建议简单把阈值降得很低。阈值过低会把噪声和相邻断层错误连成大范围多边形。正确做法是结合质量评估图、残余复核层和局部诊断判断漏检来源。

## 2.5 结果说明

输出多边形是闭合区域，不是单根线。每个多边形通常包络一条或一段断层属性响应带。CSV 结果包含面积、周长、状态和坐标信息；诊断 JSON 包含耗时、参数、覆盖率和拓扑检查等信息。正式解释时应结合原始属性图、结果叠加图和质量评估图判断结果是否符合解释习惯。

## 2.7 常用快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+O` | 选择外部 DAT 或网格文件。 |
| `Ctrl+S` | 保存参数模板。 |
| `Ctrl+Shift+O` | 打开参数模板。 |
| `Ctrl+Shift+S` | 保存运行日志。 |
| `Ctrl+Shift+P` | 导出当前视图 PNG。 |
| `F5` | 开始追踪。 |
| `Shift+F5` | 停止当前任务。 |
| `Home` | 重置视图。 |
