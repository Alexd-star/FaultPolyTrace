# 第1章 项目简介

## 1.1 项目背景

FaultPolyTrace 面向“基于平面断层属性的断层多边形自动追踪”任务。赛题关注的是：在已有平面断层属性数据的基础上，自动识别断层线性响应，并生成可用于构造解释的闭合断层多边形。传统方式需要解释人员在 GeoEast 中手工拾取或依赖层位、断点和断层解释成果生成多边形，流程较重、人工参与多、效率不稳定。本项目希望把这部分工作变成可重复、可调参、可验收的软件能力。

项目的核心目标包括四类：第一，正确读取平面断层属性数据；第二，自动追踪闭合断层多边形；第三，支持面积统计、面积阈值过滤和交切关系处理；第四，既能作为独立软件运行，也能集成到 GeoEast 平台中读写数据库对象。当前工程已经形成核心命令行程序、独立桌面软件、GeoEast Qt 启动器、GeoEast BO Runner、主控插件入口、中文文档和发布包。

## 1.2 产品定位

FaultPolyTrace 的定位是解释辅助型桌面软件与 GeoEast 集成工具。它不是单纯展示图片的脚本，也不是只对官方样例数据生效的实验程序。项目按产品化思路拆分为算法核心、文件读写、GeoEast 适配、独立界面、集成界面、验收脚本和交付文档，便于后续维护、迁移和复查。

独立软件用于外部文件处理、结果查看、参数模板和历史记录；GeoEast 插件用于在 GeoEast 工区中读取 `BOMapGrid`、写入 `BOFaultPolygon`，并配合 GeoEast 的工区底图或平面成图能力查看原始属性和追踪结果。命令行程序用于批处理、自动化验收和性能回归。

## 1.3 当前完成度概述

根据当前验收材料，项目已经具备以下能力：

- 支持读取外部 DAT、ASCII 网格和矩阵文本等外部数据。
- 支持 GeoEast `BOMapGrid` 读取和 `BOFaultPolygon` 写入。
- 支持 `ridge-belt` 断层带追踪模式、面积统计、面积阈值过滤、闭合多边形输出。
- 支持根系防黏连、弱响应延拓、残余复核层、拓扑诊断和质量图生成。
- 支持独立软件和 GeoEast 集成启动器两种图形入口。
- 支持中文操作手册、算法说明、设计说明、开发说明、发布说明和验收报告。

当前推荐发布版本为 `v1.1.2`，具体构建标识与文件哈希以发布包根目录 `构建与依赖清单.json` 为准。官方数据核验指标见 `docs/官方数据最新验收报告.md`；本地按时间生成的运行目录属于可重建产物，不作为 Git 文档固定路径。

## 1.4 适用对象

本文档体系面向四类读者。最终用户主要阅读用户手册和操作手册，关注如何选择数据、设置参数、运行追踪和查看结果。评审专家主要阅读项目简介、算法说明、测试说明和交付说明，关注是否满足赛题要求。开发人员主要阅读架构说明、代码结构说明、核心模块说明和接口文档，关注模块边界和构建方法。交付维护人员主要阅读配置说明、环境依赖与部署、历史文件说明和项目索引，关注如何打包、验收、归档和排查问题。
