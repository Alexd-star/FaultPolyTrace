# 第18章 泛化验证与公开数据指南

## 18.1 本章解决的问题

本章说明在赛方不提供人工标准答案时，怎样用可复现、可审计的证据评价 FaultPolyTrace 是否只对官方 `test.dat` 有效。核心原则是把证据分层：官方数据用于赛题主验收；独立几何真值用于定量检查漏检、误合并、边界和拓扑；公开真实数据用于检查跨数据来源的适配风险；专家局部复核用于处理二维图像中无法仅凭属性确定的对象归属。不同层级不能互相冒充。

## 18.2 证据分层

| 层级 | 数据 | 可以证明 | 不能证明 |
|---|---|---|---|
| A | 官方 `test.dat` | 赛题格式兼容、正式结果、覆盖、拓扑和速度 | 相对专家真值的 Precision、Recall 和对象数量正确性 |
| B | 80 个可控平面真值案例 | 多形态下的像元、边界、对象、中心线和拓扑指标 | 真实地质资料上的最终解释正确性 |
| C | 参数扰动案例 | 对增益、噪声和轻微平滑的结果稳定性 | 对所有采集、处理和属性算法变化的稳定性 |
| D | CRACKS/F3 纵向剖面 | 公开数据下载、校验、转换和跨域压力测试可运行 | 赛题平面断层属性的直接泛化精度 |
| E | Thebe、F3 或 Penobscot 独立地震体 | 在固定转换流程下检查跨工区运行与人工质控 | 没有独立解释时不能报告监督精度 |

## 18.3 公开数据来源

机器可读清单位于 `data/registry/public_datasets.json`，其中保存来源、许可证、引用信息、访问方式和用途边界。

1. **Thebe 专家解释地震数据集**：DOI `10.7910/DVN/YBYGBK`，CC BY 4.0。当前已通过 Dataverse API 获取 78 个文件、总计约 53.1 GB 的文件级清单，并实际下载、校验 `seistest1.npz` 与 `faulttest1.npz`。官方论文说明数组轴为 crossline、inline、sample；专家只标注特定深度范围内垂向位移大于约 20 m 的断层，因此未标注响应不能一律视为假阳性。大体积原件不进入仓库。
2. **F3 Netherlands**：公开三维地震资料，可用于独立工区运行和人工复核。它不是可直接输入的平面断层属性，必须先计算相似性、相干或其他断层属性。
3. **Penobscot**：公开访问受数据门户条款和注册流程约束，适合独立工区复核，不应绕过访问条件自动抓取。
4. **CRACKS**：DOI `10.5281/zenodo.13926822`，CC BY 4.0。项目已实际下载并校验 `images.zip` 与 `Fault segmentations.zip`，使用 expert 的 40 个标注剖面形成辅助压力测试。
5. **FaultSeg3D**：受 CC BY-NC 4.0 约束的合成地震与标签资源，可作为方法参考和补充真值来源，不能替代真实资料证据。

## 18.5 真实地震体转换

正式算法输入是二维平面断层属性，不是原始振幅地震体。`scripts/转换真实地震为平面属性.py` 先统一地震体轴顺序，再在给定时间或深度样点附近计算相邻道局部归一化相关性，以 `1 - similarity` 构造不连续性属性，最后稳健归一化并输出 FaultPolyTrace ASCII 网格。

```powershell
python scripts/转换真实地震为平面属性.py `
  --seismic <地震体.npy或.npz> `
  --axis-order xys `
  --sample-index <样点编号> `
  --half-window 5 `
  --stepout 1 `
  --max-vertical-lag 2 `
  --staging-dir <磁盘缓存目录> `
  --output data/processed/<数据集>/<切片名>
```

若同时提供标签，标签只生成 `truth_masks.npz` 用于评价，不参与属性计算。转换清单明确记录 `label_used_as_input: false`，防止标签泄漏造成虚假高分。大 NPZ 可流式暂存为 NPY，再用内存映射只读取当前 sample 窗口，避免一次性解压数 GB 数组导致内存不足。

转换器在相邻地震道之间搜索有限垂向滞后内的最佳归一化相关，以近似轻量级 dip steering。这样可减少正常倾斜反射被误判为不连续。该依据与 OpendTect Similarity 文档描述的 browse-dip 思路一致，但它仍是简化基线，不等于完整 SteeringCube、Fault Enhancement Filter 或监督学习 Fault Cube；跨工区比较必须固定转换方法和参数。

## 18.6 可控平面真值

生成器先创建断层几何和对象归属，再渲染属性响应，因此真值不来自算法输出。八类形态包括孤立曲线、近邻平行、分支、独立交叉、弱响应缺口、变宽带、边界截断和噪声足迹。规则使用随机种子和形态参数，不读取官方坐标、数据集名称或 polygon ID。

```powershell
python scripts/运行泛化验证.py generate `
  --output data/generated/planar_benchmark_80 `
  --count 80 --width 256 --height 192 --seed 20260723

python scripts/运行泛化验证.py run `
  --dataset data/generated/planar_benchmark_80 `
  --exe build/faultpolytrace.exe `
  --output examples/outputs/generalization_planar_80
```

2026-07-30 使用当前构建重新运行 80 个案例，像元 IoU 均值 `0.849627`，Precision `0.910329`，Recall `0.934742`，Boundary F1 `0.996784`，中心线覆盖 `0.999953`，漏对象 `0`，过度拆分 `0`，非法多边形和多边形异常相交均为 `0`。质量指标与 2026-07-23 的历史结果逐项一致；本轮平均和最大运行耗时为 `68.1/157 ms`，差异属于运行环境波动。

同一轮另外执行 320 次扰动验证，包括属性增益 `0.85/1.15`、高斯噪声 `σ=0.02` 和轻微平滑 `σ=0.70`。扰动结果与未扰动基线的平均 IoU 为 `0.93`，最低值为 `0.54`。增益降低是影响最大的扰动，说明分位数阈值能够吸收大部分尺度变化，但当整体响应明显减弱时仍需参数推荐或质量提示，不能把参数稳定性描述为对任意输入均不敏感。

十个独立交叉案例均被识别为一个连通对象，因此对象误合并总数为 `10`。这不是应被隐藏的测试噪声，而是当前方法的明确边界：二维属性交点缺少先后关系或语义标签时，局部拓扑不足以唯一决定一个分支对象还是两个独立对象。后续全局分支归属必须以路径方向、属性支撑、背景隔离和专家局部解释共同门控，不能为把计数清零而强制拆分。

## 18.7 Thebe 真实平面条带验证

`seistest1.npz` 和 `faulttest1.npz` 的实际数组形状均为 `100 × 3174 × 1537`，分别对应 crossline、inline 和 sample。固定 sample 后得到 `100 × 3174` 的真实平面条带。项目按专家标注密度分层选择 `971、1097、1276、1451` 四个 sample，参数保持一致，不根据结果单独调阈值。

有限垂向滞后属性在 sample 1276 上相对未引导属性取得小幅改善：IoU 从 `0.038355` 提升到 `0.042955`，Recall 从 `0.189067` 提升到 `0.208605`，Boundary F1 从 `0.126870` 提升到 `0.141372`。这说明倾角补偿方向有依据，但不足以独立解决真实数据域差异。

四个切片的平均 IoU 为 `0.053651`，Precision 为 `0.094033`，Recall 为 `0.159762`，Boundary F1 为 `0.169602`，细线走廊 F1 为 `0.134003`；74 个专家连通对象中漏 33 个，误合并 3 次、过度拆分 13 次，非法多边形和多边形异常相交均为 0，平均核心运行耗时 `325.8 ms`。视觉复核显示简单相似性属性仍包含大量地震纹理响应，而专家断层是稀疏长线。主要限制是属性预处理与赛题已提供断层属性之间存在输入域差异，同时专家标签并不覆盖所有弱断层响应。

该结果证明真实地震体链路、标签隔离、内存映射、追踪和统一评价可以完整运行，也客观否定了“当前转换器已达到成熟商业断层属性质量”的说法。正式比赛核心接收的是平面断层属性；若要把原始地震体转换升级为产品能力，应另行建立 dip field、结构导向滤波、多尺度相干和独立工区标注验证，不能使用 Thebe 标签参与属性生成。

## 18.8 CRACKS 辅助压力测试

CRACKS 的数据是 F3 纵向地震剖面，专家标注是细线；FaultPolyTrace 的目标则是平面断层属性上的带状闭合多边形。两者输入域和输出语义不同。本项目仍保留该测试，用来检查公开真实数据接入和跨域风险，但不据此调低正式平面参数。

40 个 expert 剖面均完成运行，非法拓扑和多边形相交为 `0`，平均和最大耗时为 `152.5/185 ms`。像元 IoU 仅 `0.047327`，中心线覆盖 `0.050112`，细线走廊 F1 `0.092607`。该负向结果说明当前由简单横向相邻道相似性生成的纵向属性不能直接替代赛题平面断层属性，也证明测试体系没有只保留好看的结果。

## 18.9 指标定义

| 指标 | 含义 | 主要风险 |
|---|---|---|
| Pixel Precision | 输出覆盖像元中属于真值的比例 | 对细线真值评价带状结果时会偏低 |
| Pixel Recall | 真值像元被输出覆盖的比例 | 不能发现大量包入背景 |
| IoU | 预测与真值交并比 | 对对象归属和局部边界不够敏感 |
| Boundary F1 | 容差范围内边界匹配的调和均值 | 容差必须随网格分辨率记录 |
| ASSD / HD95 | 平均对称边界距离和 95% Hausdorff 距离 | 对坐标单位和异常边界敏感 |
| Merge / Split / Miss | 对象误合并、过度拆分和漏对象 | 依赖真值对象定义，交叉语义可能有歧义 |
| Centerline Coverage | 专家线或几何中心线被结果覆盖的比例 | 单独使用不能约束结果带宽 |
| Corridor Precision/F1 | 输出落在中心线容差走廊内的程度 | 容差过大会掩盖边界过宽 |
| Topology | 非法几何、开放、自交和异常相交 | 合法不等于地质解释正确 |

## 18.11 当前结论与剩余工作

当前证据足以说明正式算法不是只对一个固定坐标或固定对象编号生效，并且在八类平面形态上具备较强的像元、边界、中心线和拓扑表现。按赛题要求的“已提供平面断层属性输入”评价，项目已达到较强的竞赛与工程试用水平；按真实生产环境的“跨工区自动输出即可直接定稿”评价，目前仍应定位为自动追踪与质量检查工具，结果需要解释人员进行局部复核。

当前正式源码在官方数据上输出200个保留多边形，强、弱响应覆盖率分别为`99.8552%`和`97.6837%`，内环及其他完整拓扑问题均为0，规范化CSV SHA256为`EE7473CD04A3EA988166DD4502EEE70D4FB4A0D674135541A9B38490C3B91369`。支撑包络分离与作用域弱桥已通过多形态、92套独立平面数据、GeoEast回读和稳定性门控；关闭局部防黏连可回退到上一正式结果。210个残余补追候选提高了覆盖率，但低支撑短桥代理略有增加，未进入默认主线。物理形态学、交点簇图、多尺度证据和自适应边界继续以影子或复核模式运行；230个Python后处理版本属于历史探索结果，不作为正式最佳结果。

官方数据仍有 11 个局部复核候选：7 个弱线性残余、2 个数据边界截断、1 个局部包络不足和 1 个端点轻微未包络。弱线性残余没有人工真值，既可能是未覆盖断层，也可能是噪声；边界截断不应自动外推。真正适合自动修补的只有局部包络不足和端点微缺口，而且必须同时满足方向连续、属性支撑、根系一致、背景隔离和拓扑门控。

当前算法不是理论上的最优算法，也不存在脱离输入属性质量和对象定义的通用最优解。现有方法的优势是无需训练、速度快、结果可解释、闭合拓扑稳定，适合赛题给定的平面属性；短板是交切处对象语义不足、正式主线仍采用局部根系分组，以及输入属性域变化时质量下降明显。下一步合理的升级顺序为：

1. 为独立交叉、近邻分支和端点缺口建立局部对象级人工真值，先固定评价口径。
2. 将现有多尺度方向、属性、宽度和背景隔离的精确分支匹配器由实验影子模式推进为可回退候选，并以误合并、过拆分和参数稳定性共同门控。
3. 将弱响应处理进一步统一为路径级传播，限制连续低支撑长度，避免整连通块式接纳造成远距离串联。
4. 对端点缺口使用受限最优路径搜索，只在候选框内搜索，并设置最大距离、转角、累计支撑和背景穿越代价。
5. 在追踪前增加可选的多尺度方向场与脊线增强，提高弱线连续性，同时保留原始属性和增强属性的双通道质控。
6. 增加第二套独立平面断层属性及双人局部解释，报告 Boundary IoU、对象误合并/过拆分、中心线连通性和参数扰动稳定性。

监督学习或基础模型在拥有同域训练标签时可能提升弱响应召回，但公开研究同样显示地震资料域差异会显著削弱跨工区效果。因此在本赛题范围内，更稳妥的路线不是用学习模型整体替换现有算法，而是采用“确定性追踪主线 + 全局分支优化 + 不确定性复核层”的混合方案。
