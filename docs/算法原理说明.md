# 算法原理说明

本文说明 FaultPolyTrace 的核心算法原理，用于赛题 7“基于平面断层属性的断层多边形自动追踪”的软件设计文档、答辩讲解和代码评审材料。

## 1. 算法目标

输入是一张二维平面断层属性网格。属性值越高，越可能对应断层位置。算法目标是从该属性网格中自动追踪断层多边形，并满足以下要求：

- 每个多边形为闭合区域。
- 支持面积统计。
- 支持按用户设定的面积阈值过滤小多边形。
- 能合理处理断层断续、分叉和交切关系。
- 边界尽量平滑自然。
- 核心处理速度满足赛题 1 分钟内完成的性能要求。
- 结果可写入 GeoEast 数据库。

## 2. 总体流程

```text
平面断层属性网格
    ↓
阈值分割
    ↓
形态学闭运算
    ↓
骨架化
    ↓
骨架图分析
    ↓
短分支剪枝 + 断点补连
    ↓
断层带缓冲
    ↓
连通域提取
    ↓
闭合边界追踪
    ↓
边界简化和平滑
    ↓
面积统计、面积过滤、拓扑诊断
    ↓
闭合断层多边形
```

本项目推荐使用 `ridge-belt` 模式。该模式不是简单圈定高属性值区域，而是先识别断层中心结构，再由中心结构生成闭合断层带多边形，更符合地质解释中断层通常呈线性或带状展布的特点。

## 3. 阈值分割

首先将连续属性值转换为二值断层候选区域。

官方数据推荐使用分位数阈值：

```text
percentile = 0.98
```

含义是保留属性值最高的一部分像元作为强断层响应。分位数阈值比固定阈值更适合不同数据体，因为不同数据体的属性值范围可能不同。

分割规则为：

```text
属性值 >= 有效阈值 → 断层候选像元
属性值 <  有效阈值 → 背景像元
```

为提高性能，程序使用 `std::nth_element` 计算分位数阈值，避免对全部网格值做完整排序。

## 4. 形态学闭运算

断层属性响应常存在小断点、小空洞或局部弱响应。算法使用形态学闭运算改善二值区域连续性：

```text
闭运算 = 先膨胀，再腐蚀
```

作用包括：

- 连通距离很近的断层片段。
- 填补断层带内部小空洞。
- 保持断层整体带状形态。
- 降低后续骨架化中的碎片化风险。

官方推荐参数：

```text
close radius = 1
```

## 5. 骨架化

直接对二值高值区域追踪边界，容易得到块状、锯齿状或局部粘连的区域。为更好表达断层走向，算法先将断层候选带细化为中心线骨架：

```text
宽断层带 → 一像素宽中心骨架
```

骨架化后可以更清楚地分析：

- 断层端点。
- 断层交点。
- 断层分支。
- 断续缺口。
- 主干与短噪声枝杈。

该步骤是 Ridge-Belt 方法区别于普通连通域追踪的核心。

## 6. 骨架图分析

骨架化结果会转换为图结构：

```text
骨架像元 = 图节点
像元邻接关系 = 图边
```

根据每个骨架点的 8 邻域邻居数量进行分类：

| 类型 | 判据 | 地质含义 |
|---|---|---|
| 端点 | 邻居数为 1 | 断层终止点或断续处 |
| 普通点 | 邻居数为 2 | 断层主干上的连续点 |
| 交点/分叉点 | 邻居数不等于 2，且非端点 | 断层交切、分叉或复杂连接处 |

算法随后将骨架拆分成一条条分支，并统计每条分支的：

- 分支长度。
- 平均属性值。
- 最大属性值。
- 起点是否为交点。
- 终点是否为交点。
- 是否被保留或剪枝。

这些信息会输出到分支 CSV，便于解释交切关系和算法行为。

## 7. 短分支剪枝

断层属性图中常存在毛刺和噪声枝杈。如果直接保留所有骨架分支，会产生不合理的小多边形或复杂边界。

算法设置最短分支阈值：

```text
min branch length = 6
```

短于该阈值的分支会被剪掉。该策略可以：

- 减少噪声。
- 保留主要断层骨架。
- 提高多边形边界稳定性。
- 降低后续拓扑复杂度。

## 8. 断点补连

断层属性可能因成像弱、局部噪声或属性不连续而断开。算法在骨架端点之间执行保守补连。

补连同时满足两个条件：

```text
端点距离足够近
端点延伸方向夹角合理
```

官方推荐参数：

```text
max gap distance = 8
max gap angle = 45°
```

这意味着只有两个端点距离较近，并且延伸方向基本一致时，算法才会补连。这样既能处理断续断层，又能避免把无关断层错误连接。

## 9. 断层带缓冲

骨架是线结构，但赛题要求输出断层多边形。因此算法将骨架按指定半径扩展为带状区域：

```text
骨架线 → 缓冲 → 断层带区域
```

官方推荐参数：

```text
belt radius = 2
```

该步骤生成闭合边界追踪的基础二值区域。

## 9.1 断层带后闭合

实际平面断层属性图常存在弱响应、局部空洞、断续成像和骨架剪枝现象。同一条断层在二值化和骨架化后可能被分割为多个很近的小段。若直接对这些小段缓冲成带，结果图上会出现“串珠状”或“胶囊串”现象：每个小段都是闭合多边形，但整体解释连续性不足。

为改善这一问题，算法在骨架缓冲之后增加断层带后闭合：

```text
骨架线 → 缓冲成带 → 属性约束贴合 → 带状区域后闭合 → 连通域追踪
```

带后闭合与属性闭运算的区别：

- 属性闭运算作用在原始阈值掩膜上，会影响后续骨架结构。
- 带后闭合作用在已经形成的断层带上，主要填补近邻断层带之间的小缺口。

因此，带后闭合更适合专门减少串珠状分段，一般比全图降低阈值更稳健。

推荐参数：

```text
post belt close radius = 1
```

参数选择原则：

- `0`：最保守，适合交切密集且担心误连的区域。
- `1`：均衡推荐，可减少小断口和串珠状视觉问题。
- `2`：连续性更强，但存在不同断层带误合并风险，适合宽断层带或方案对比。

若结果出现不同断层误连，应降低带后闭合、最大断距或最大夹角。

## 9.2 属性约束断层带

早期 Ridge-Belt 结果采用固定带宽从骨架线向两侧扩展。该方法连续性好、拓扑稳定，但在显示上会出现一个常见现象：红色闭合边界位于黑色断层响应中心线两侧，肉眼看起来像“边界和原始线之间有空隙”。这并不一定是错位，因为断层多边形本来是闭合区域，边界不应等同于中心线；但若固定带宽过宽，确实会降低与原始属性带的贴合感。

为提高结果与组委会示意图的一致性，当前版本新增“属性约束断层带”：

```text
原始属性候选区 → 属性包络
骨架缓冲区 → 连续断层带
连续断层带 ∩ 属性包络 + 原始属性候选区 → 贴合型闭合断层带
```

该策略的作用是：

- 保留骨架补连带来的连续性。
- 避免固定带宽无约束外扩。
- 将真实属性响应重新纳入多边形区域。
- 使边界更贴近原始断层属性带。
- 降低“胶囊串”和“离线感”。

当前官方数据推荐启用：

```text
attribute constrained belt = true
attribute envelope radius = 1
```

若解释目标更保守，可关闭该选项；若断层属性本身较宽，可适当增大属性包络半径或使用宽断层带预设。

浅细断层的处理不能简单依赖全局降阈值。全局降阈值会把大面积弱背景和噪声连通域引入，可能造成过度合并。FaultPolyTrace 的高召回方案采用“强种子约束 + 弱连通域形态约束”：

```text
强断层响应作为种子
弱响应连通域必须接触强种子邻域
弱响应连通域必须满足规模或长宽比约束
通过约束后才参与后续骨架化
```

这样可以补充浅细但连续的断层响应，同时避免把整片弱噪声背景误解释为断层多边形。

## 10. 连通域提取

缓冲后的二值区域中，每个连通块代表一个候选断层多边形区域。算法采用 8 邻域连通：

```text
上、下、左、右、左上、右上、左下、右下
```

每个连通域独立追踪边界，形成一个或多个候选边界环。默认选取面积最大的外边界环作为该断层多边形的主体边界。

## 11. 闭合边界追踪

边界追踪基于像元外边界。

若一个断层像元的某一侧邻接背景或超出网格范围，则该侧为外边界。算法收集所有外边界边，并按端点连接成闭合环：

```text
断层像元外侧边 → 边集合 → 首尾连接 → 闭合多边形环
```

该方法具有以下优点：

- 多边形天然闭合。
- 可保留凹形边界。
- 对弯曲、分叉、断续后的复杂形态适应性较好。
- 不依赖人工拾取断层多边形。

需要特别注意的是，一个连通域内部可能包含多个有效外边界。例如多条细长断层段在斜向角点处相接，或交切区附近形成多个外轮廓。如果只保留面积最大的一个边界环，会遗漏同一连通域中的较小强响应断层段。当前版本会识别并输出连通域中的所有有效外边界环，再由面积阈值决定是否保留：

```text
连通域 → 多个外边界环 → 分别生成闭合多边形 → 面积过滤
```

该策略提高了强响应覆盖率，避免“主干被追踪，但同域内短中等强响应段被丢弃”的问题，也提升了软件在交切、密集和细碎断裂场景中的泛化能力。

## 12. 边界简化和平滑

像元边界通常存在锯齿。为了使结果更接近人工解释多边形，算法提供两级边界后处理。

第一步是 Douglas-Peucker 简化：

- 去除冗余边界点。
- 保留主要形态。
- 降低输出复杂度。
- 提高后续拓扑诊断和写出性能。

第二步是 Chaikin 平滑：

- 缓和直角和锯齿。
- 使边界更自然。
- 改善图形展示效果。

普通 Chaikin 平滑有一个工程副作用：闭合环会轻微向内收缩。对断层多边形来说，这种收缩可能让原本已经被追踪到的端点或交切附近高属性像元落到边界外，视觉上表现为“边界平滑了，但局部贴合略差”。当前版本采用面积保持型平滑：

```text
原始闭合边界
    ↓
Douglas-Peucker 简化
    ↓
Chaikin 平滑
    ↓
计算平滑前后面积
    ↓
若平滑后面积缩小，则围绕多边形质心做有限比例补偿
    ↓
重新计算面积、周长和拓扑
```

该补偿有两个约束：

- 只在平滑导致面积缩小时触发。
- 单次补偿比例设有上限，避免把多边形无约束外扩到邻近断层。

官方推荐参数：

```text
simplify tolerance = 2
smooth iterations = 1
```

当前官方数据采用面积保持型平滑后保持：

```text
开放环 = 0
自相交 = 0
多边形异常相交 = 0
强响应覆盖率 = 99.6217%
弱响应覆盖率 = 96.9351%
```

多边形之间的接触或交切记录会作为质控明细输出。该记录不等同于错误，因为断层解释中允许存在交切、搭接、相邻接触和局部重叠显示关系。真正的硬性错误是开放环、自相交以及明显由误合并造成的大范围异常相交。

## 13. 残余线性二次追踪

根系追踪和属性约束断层带能够解决大部分主干断层，但在实际资料中仍会存在局部细弱、断续、低对比度的线性残余。如果完全忽略这些残余，结果会显得不够完整；如果全局降低阈值，又容易把近邻断层误合并。当前版本保留残余线性二次追踪作为高召回复核能力，但默认主交付方案不启用该步骤。

```text
主追踪结果
    ↓
候选断层带覆盖掩膜
    ↓
最终保留多边形覆盖掩膜
    ↓
未覆盖弱线性响应检测
    ↓
形态、长度、属性强度和规模约束
    ↓
补充闭合小多边形
```

该步骤采用“双覆盖”思想：

- `candidateCoveredMask` 记录所有候选断层带覆盖范围，用于避免在候选带附近反复生长边缘碎片。
- `coveredMask` 只记录最终保留多边形覆盖范围，用于统计真实输出覆盖效果。

这样可以同时解决两个矛盾：被面积过滤掉的候选小块不会诱导二次追踪过度生长；真正未覆盖的线性残余仍可被二次追踪补充。

复核参数：

```text
residual percentile = 0.955
residual fill radius = 4
residual trace min length = 6
residual trace max cells = 80
residual covered guard radius = 0
```

高召回复核参数：

```text
residual trace min length = 5
residual trace max cells = 120
```

贴合融合主交付方案默认关闭残余二次追踪，优先保持 200 个量级的整体连续断层带输出。高召回复核方案可用于解释人员检查更细弱的残余响应，但不作为默认自动交付结果。

## 13.1 主干归属与防黏连

用户提出的“树根”类比可以理解为主干归属判断：如果一个候选响应沿着断层中心线向前后追踪，能够回到同一条主干，它更可能属于同一条断层；如果中间隔着背景低值区，且没有合理方向、距离和属性支撑，则不应仅因空间接近而合并。

工程实现中要区分两个层面：

- 主干归属约束：用于判断断点补连、限制跨线外扩、识别近邻断层是否同源。
- 分支独立输出：把每个主干分组单独生成多边形。

当前默认方案只使用前者的思想，不默认启用后者。原因是分支独立输出虽然能减少某些黏连，但会把连续断层打碎成大量局部闭合片，造成“串珠状”和多边形数量暴涨，反而降低产品质量。

最新版本在此基础上增加了“根系防黏连切后验收”。它不是把所有根系边界都切开，而是按以下步骤受控处理：

1. 先生成候选背景桥切分点。候选点通常位于不同主干争抢、原始属性值接近背景零值的位置。
2. 对每个原始连通断层带单独模拟切开。
3. 检查切开后是否形成至少两个足够大的主体。主体像元数和主体比例可由参数控制，默认 `rootAntiMergeMinPartCells=0` 表示自动估计，`rootAntiMergeMinPartRatio=0.12` 表示每个主体至少应占原连通体的一定比例。
4. 如果切开后只是一个大主体加少量小碎片，则自动回退该连通体的切分，避免把连续断层打碎。
5. 只接受通过验收的低属性背景桥切分，并重新执行闭合边界追踪、面积过滤和拓扑诊断。

这一机制对应用户界面中的 `防黏连增强` 预设。它适用于叠合图中明确看到近邻不同脉络被连成一片的情况。正式默认主线仍保持 `贴合融合推荐`，因为默认结果更强调稳定连续和广泛适用；防黏连增强作为有证据、有回退的高级模式使用。

## 14. 面积统计和面积过滤

每个多边形都会统计：

- 面积。
- 周长。
- 像元数量。
- 平均属性值。
- 最大属性值。

面积使用闭合多边形鞋带公式：

```text
Area = 1/2 * |Σ(x_i y_{i+1} - x_{i+1} y_i)|
```

用户可设置面积阈值过滤小多边形：

```text
min area = 120
```

输出 CSV 中保留 `status` 字段：

```text
kept      表示保留
filtered  表示被面积阈值过滤
```

这样既满足过滤需求，又便于评审查看阈值对结果的影响。

当前版本还支持自适应面积过滤：面积低于阈值但形态细长、属性值足够高的小断层段可被保留；低强度孤立噪声仍会过滤。该策略用于兼顾“过滤小噪声”和“保留真实细碎断层”。

## 15. 拓扑诊断

为了保证输出质量，算法会对结果执行拓扑诊断：

- 开放环数量。
- 自相交多边形数量。
- 多边形之间接触、交切或相交记录。

拓扑诊断会输出到 JSON 和明细 CSV。为控制平滑后线段数量增加带来的耗时，程序增加了多边形包围盒和线段包围盒剪枝，只对可能相交的线段执行精确相交判断。

官方数据当前推荐主交付结果：

```text
开放环: 0
自相交: 0
多边形异常相交: 0
保留多边形数量: 204
强响应覆盖率: 99.622%
弱响应覆盖率: 96.935%
```

硬性门槛为开放环 0、自相交 0、明显异常相交 0、核心耗时小于 1 分钟。局部接触和交切在地质解释中可能合理，但大范围误合并需要通过图件复核和局部参数调整处理。

## 16. 性能优化

赛题要求核心算法在 1 分钟内完成。当前实现显著优于该要求。

主要优化包括：

- 分位数阈值使用 `std::nth_element`，避免全量排序。
- GeoEast DAT 使用字符级快速解析，降低 82MB 文本读入耗时。
- 拓扑诊断加入包围盒剪枝，避免大量无效线段相交检测。
- Douglas-Peucker 使用平方距离比较，减少 `sqrt` 调用。
- CSV/WKT 采用流式输出，减少大字符串临时分配。
- 核心数据结构使用 `std::vector` 和 RAII，降低内存泄漏风险。

官方数据性能报告：

```text
当前推荐主交付方案核心追踪耗时: 约 421 至 447 ms
当前推荐主交付方案总耗时: 约 1301 至 1361 ms
```

该耗时包含弱响应延拓、属性约束断层带、闭合边界追踪、平滑和拓扑诊断，远低于赛题 1 分钟要求。

## 17. 为什么适合地质勘探场景

地质断层在平面属性图上可能表现为：

- 长条状。
- 弯曲状。
- 分叉状。
- 断续状。
- 交切状。
- 局部弱响应。
- 噪声毛刺。
- 多条断层相邻。

普通阈值连通域方法容易出现断层断开、噪声多边形和交切处混乱等问题。Ridge-Belt 方法先提取断层中心结构，再由中心结构生成闭合断层带：

```text
属性响应 → 中心线结构 → 保守补连 → 断层带 → 闭合多边形
```

这更符合断层作为线性或带状构造的地质认识，因此比直接圈定高值区更适合赛题要求。

## 18. 一句话总结

FaultPolyTrace 以平面断层属性网格为输入，通过“分位数阈值分割、形态学处理、骨架图分析、短分支剪枝、断点补连、断层带缓冲、闭合边界追踪、边界简化平滑、面积统计和拓扑诊断”，自动生成闭合、自然、可统计、可过滤、可写入 GeoEast 的断层多边形。
