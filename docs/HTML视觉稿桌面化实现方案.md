# HTML 视觉稿桌面化实现方案

文档版本：V1.0
编制日期：2026-06-01
适用范围：`geoeast_plugin/qt_launcher`、GeoEast 菜单入口、评审发布包图形界面
参考视觉稿：`E:/DownLoad/gemini-code-1780243953572.html`

## 1. 目标

本次改造的目标，是在不改变算法、runner 调用方式、GeoEast 数据库读写能力和离线交付策略的前提下，把用户提供的 HTML 视觉稿转化为真实可运行的 Qt 桌面软件界面。界面需要高度复刻 HTML 视觉稿中的结构、颜色、控件密度、边距和工作区比例，同时按照桌面软件的真实使用方式处理窗口缩放、自适应和运行速度，而不是把网页直接嵌入软件。

改造后的启动器应满足以下目标：

1. 保留现有所有功能：数据库配置、网格刷新、输入输出设置、DAT 导入、参数预设、颜色和线宽设置、运行、停止、日志显示。
2. 采用 GeoEast 风格主框架：顶部菜单栏、工具栏、左侧参数面板、中央渲染视图区、右侧色标、底部日志和状态栏。
3. 控件尺寸、边距和视觉层级参考 HTML 视觉稿，保持紧凑、清晰、可扫描。
4. 数据库底层配置从主界面移入专用弹窗，减少主界面信息压力。
5. 左侧参数栏保持接近 HTML 的固定宽度，中央渲染区和日志区随窗口自适应扩展，保证用户放大或缩小时界面不挤压、不错位。
6. 继续使用 Qt Widgets 原生控件，确保启动速度、运行库部署、GeoEast 集成和异机运行可靠性。

## 2. 技术栈选择

推荐技术栈保持为：

| 层级 | 选择 | 原因 |
|---|---|---|
| 桌面 UI | C++17 + Qt Widgets | 与 GeoEast 环境一致，启动快，部署体积可控，便于继续使用现有 qmake 工程 |
| 构建系统 | qmake + `scripts/build_qt_launcher.ps1` | 已验证可调用 GeoEast 自带 Qt 5.15.2 和 `windeployqt` |
| 后端执行 | `faultpolytrace_geoeast_runner.exe` | 保持现有 GeoEast BO 数据库读写链路 |
| 离线算法 | `bin/faultpolytrace.exe` | 保持算法模块独立运行能力 |
| 配置持久化 | `faultpolytrace_launcher.ini` + `QSettings` | 已有机制稳定，便于用户修改后自动保存 |

不采用 Qt WebEngine 或 WebView。原因是 WebEngine 会显著增加运行库体积和部署复杂度，也会让 GeoEast 集成入口更容易出现依赖不完整、加载路径混乱和启动变慢的问题。当前界面是专业桌面工具，Qt Widgets 的原生控件更符合 GeoEast 既有生态。

## 3. 视觉稿到 Qt 的映射

| HTML 区域 | Qt 实现 | 说明 |
|---|---|---|
| `.menubar` | `QMenuBar` | 菜单包含 GeoEast、文件、编辑、视图、断层、层位、工具、帮助 |
| `.toolbar` | `QToolBar` | 使用小图标和文字按钮，包含数据库配置、刷新网格、保存预设、帮助等 |
| `.sidebar` | `QFrame + QScrollArea` | 左侧固定宽度参数面板，内部使用 `QGroupBox` 分组 |
| `.form-row` | `QGridLayout` 行式表单 | 标签左对齐，控件右对齐，保持 HTML 视觉稿的紧凑边距 |
| `.action-dock` | 左侧底部固定按钮栏 | 蓝色主按钮“开始追踪”，灰色按钮“停止” |
| `.canvas-area` | 自绘 `RenderViewWidget` | 绘制浅色网格背景、视图区标题和空状态提示 |
| `.colorbar-panel` | 自绘 `ColorBarWidget` | 绘制红黄绿青蓝竖向色标，标注 0 和 100 |
| `.log-dock` | `QFrame + QTextEdit` | 底部日志区，标题为“运行日志与输出信息” |
| `.statusbar` | `QFrame + QLabel` | 显示坐标、数据库状态、项目和当前网格 |
| `.modal` | 原生 `QDialog` | 数据库与环境底层配置弹窗，复用现有配置字段 |

## 4. 主界面信息架构与自适应策略

主界面默认尺寸建议为 `1280 x 760`，最小尺寸为 `1024 x 680`。这比 HTML 截图更适合桌面窗口，也能容纳当前较多算法参数。

主界面结构如下：

```text
顶部菜单栏
顶部工具栏
┌────────────────────────┬───────────────────────────────┬────────┐
│ 左侧参数面板            │ 中央 GeoEast Basemap 视图区     │ 色标   │
│ 数据管理                │ 浅色网格、标题、运行占位提示     │ 0-100  │
│ 追踪参数                │                               │        │
│ 形态与拓扑约束          │                               │        │
│ 枝干细节与修补          │                               │        │
│ 开始追踪 / 停止         │                               │        │
├────────────────────────┴───────────────────────────────┴────────┤
│ 运行日志与输出信息                                               │
├──────────────────────────────────────────────────────────────────┤
│ 坐标 / 数据库连接状态 / 当前项目 / 当前网格                       │
└──────────────────────────────────────────────────────────────────┘
```

自适应原则如下：

1. 左侧参数面板保持约 `345px` 宽度，复刻 HTML 视觉稿的参数栏比例。该区域内部使用滚动条，窗口高度不足时不压缩控件。
2. 中央视图区使用可扩展控件，窗口变宽或变高时优先扩展视图区，便于后续加入输入网格与结果多边形预览。
3. 右侧色标保持固定窄栏，避免色标在窗口缩放时变形。
4. 底部日志区保持约 `120px` 高度，符合 HTML 视觉稿，也避免日志区挤占主要渲染区域。
5. 最底部状态栏固定高度，用于显示坐标、数据库、项目、当前网格和状态。
6. 数据库配置弹窗采用固定推荐宽度和表单列伸缩，内容较长时文本框横向扩展，不影响主窗口布局。

## 5. 功能保持要求

本次界面改造只调整界面组织方式，不改变已有功能接口。必须保留以下行为：

1. 【刷新网格】调用 `faultpolytrace_geoeast_runner.exe --list-grids`。
2. 【开始追踪】组装原有 `traceArgs()` 参数并启动 runner。
3. 【停止】终止当前 `QProcess`。
4. 颜色选择继续写入 `--polygon-color`。
5. 线宽继续写入 `--polygon-linewidth`。
6. 勾选“从官方 DAT 导入/覆盖输入网格”后继续传入 `--import-geoeast-dat` 和 `--overwrite-grid`。
7. 参数预设继续调用 `applyParameterPreset()`。
8. 配置继续通过 `QSettings` 保存到启动器旁边的 `faultpolytrace_launcher.ini`。
9. 日志继续实时显示 stdout 和 stderr。

## 6. 新增交互

新增以下交互能力：

1. 【数据库与环境底层配置...】工具栏按钮打开专用配置弹窗。
2. 弹窗内可配置 Runner、GeoEast 根目录、GeoEast 数据根目录、PG 主机、端口、数据库、项目、用户和密码。
3. 【应用并保存配置】写回主界面字段并立即保存到 ini。
4. 【保存预设】保存当前配置并在日志中提示。
5. 【帮助】在日志中提示推荐阅读文档路径，后续可扩展为打开用户手册。
6. 中央视图区在未接入真实图像渲染前提供稳定的白底网格占位和当前运行上下文提示。

## 7. 测试与验收

界面改造完成后必须执行：

```powershell
.\scripts\build_qt_launcher.ps1
```

构建成功后执行启动烟测：

```powershell
$exe = 'C:\Users\26312\Documents\BGPCup\FaultPolyTrace\geoeast_plugin\qt_launcher\faultpolytrace_launcher.exe'
$p = Start-Process -FilePath $exe -PassThru
Start-Sleep -Seconds 3
if ($p.HasExited) { exit 1 } else { Stop-Process -Id $p.Id -Force }
```

为了确认界面改造没有影响算法和独立运行能力，还应执行：

```powershell
.\scripts\run_smoke_test.ps1
python .\scripts\泛化鲁棒性验证.py
```

验收通过标准：

1. Qt 启动器可正常打开，不出现 Qt 入口错误。
2. 主窗口显示菜单栏、工具栏、左侧参数、中央视图区、色标、日志和状态栏。
3. 数据库配置弹窗可打开、取消、应用并保存。
4. 开始、停止、刷新网格、颜色选择、保存预设等按钮连接正常。
5. CLI 烟测和泛化鲁棒性验证不回退。

4. 帮助按钮打开正式用户手册。
5. 通过项目自有资源文件打包正式图标，替代系统标准图标。
