核验日期：2026-08-01

正式方案：统一产品默认方案（200个保留多边形）

## 1. 验收结论

当前C++正式线在官方`test.dat`上生成212个候选多边形，经面积与形态过滤后保留200个闭合多边形。强响应覆盖率为99.855208%，弱响应覆盖率为97.651143%，非零响应覆盖率为95.396200%。开放环、自相交、边界冲突、无效几何、完整包含和内部面积重叠均为0，GEOS 3.11.4交叉验证结果有效。

50次连续运行的输出SHA256完全一致，总耗时中位数为3532 ms、P95为3824 ms、最大值为3869 ms；核心追踪P95为2172 ms。峰值工作集不超过52.24 MB，前后采样窗口工作集趋势为0.096 MB，句柄趋势为0，明显低于赛题一分钟限制。

正式结果规范化CSV SHA256为：

```text

```

## 4. GeoEast闭环

GeoEast写入采用暂存对象写入、暂存回读、目标替换、目标回读、失败回滚和暂存清理。正式200结果完成62032个外环顶点的起点和方向无关逐点核验，写前与读回规范化几何哈希均为`80FBFD410F9C0F36`；段数、闭合状态、主键、样式和完整拓扑全部一致。

GeoEast SDK的`BOFaultPolygon`结构和官方ASCII格式没有外环/内环角色字段。为避免把9个内环误写为9个独立断层多边形，GeoEast对象保存外边界，完整含孔几何继续保存在CSV/WKT中；事务报告明确记录该兼容策略。
