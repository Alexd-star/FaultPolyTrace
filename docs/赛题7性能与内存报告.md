### 1.1 本轮增量优化复验

2026 年 7 月 28 日在同一开发机、同一官方数据和同一正式参数下完成增量优化复验。优化未修改阈值、追踪、拓扑或多边形生成逻辑，主要调整大文件缓冲、预览文件流式解析和无效重绘抑制。

| 指标 | 优化前单次基线 | 优化后 3 次复验 |
|---|---:|---:|
| 总耗时 | 1552 ms | 平均 1393 ms，范围 1352～1416 ms |
| 读取耗时 | 376 ms | 平均 311 ms |
| 写出耗时 | 359 ms | 平均 323 ms |
| 保留多边形 | 214 | 214 |

正式结果 CSV、枝干 CSV 和拓扑 CSV 的 SHA256 在优化前后完全一致。该对比说明本轮性能收益来自输入输出和界面数据通路，而不是减少质量检查或改变算法结果。单次耗时仍会受磁盘缓存和系统负载影响，因此报告同时保留结果哈希、拓扑和连续运行检查作为质量门禁。

### 1.2 预览交互与交付体积

后续增量调整继续限定在显示与交付通路。独立软件的 GeoEast DAT 预览使用固定五列数值解析，减少逐采样行的临时容器分配；独立软件和 GeoEast 插件将结果环预编译为绘制路径，平移、缩放和窗口刷新时只更新坐标变换。网格图像缓存、屏幕像素线宽、抗锯齿和图层独立开关保持原有语义。该优化不修改核心算法，也不修改 CSV/WKT 几何。

发布包构建器不再复制本机 `examples/outputs/official` 下的历次性能采样，只收录当前正式多边形、枝干、诊断、拓扑和配套图件。试打包结果如下：

| 指标 | 调整前 | 调整后 |
|---|---:|---:|
| 发布目录 | 约 216 MiB | 164.71 MiB |
| `examples/` | 64.33 MiB | 20.20 MiB |
| Qt 翻译资源 | 约 7.03 MiB、46 个文件 | 229.19 KiB、2 个文件 |
| ZIP | 约 96.32 MiB | 86.68 MiB |

体积调整不删除仓库或本地历史文件，只控制正式客户包的收录范围；官方复现脚本依赖的四类正式结果文件仍完整保留。

## 2. 连续运行稳定性

正式参数连续运行 50 次得到：

- 50 次结果 SHA256 完全一致。
- 最大总耗时 1672 ms。
- 峰值 Working Set 38,625,280 bytes。
- 首尾内存趋势 -0.006 MB。
- 句柄趋势 0。
- 失败注入检查通过。

该测试证明当前输入和参数下结果确定、进程资源趋势稳定。它不能替代长期服务运行、不同硬件和全部异常输入的内存分析。

本轮优化后另执行 10 次快速稳定性复核：最大总耗时 1405 ms，峰值 Working Set 38,371,328 bytes，内存趋势 -0.015 MB，句柄趋势 0，失败注入检查通过。该快速复核用于确认本轮流式解析和缓冲调整没有引入资源回归，不替代上述 50 次正式稳定性记录。

## 3. 内存控制

- 栅格、掩膜、分支和多边形使用标准容器和 RAII。
- 局部质量模块在栅格化前检查对象包围盒和最大单元预算。
- 拓扑诊断先做包围盒过滤，再做精确相交检查。
- CSV、JSON 和分支结果采用流式写出。
- GeoEast 对象转换为轻量 `Grid2D` 后再进入核心算法。

## 5. 优化边界

当前主要质量风险不是速度。后续优化应优先保证边界、误合并和对象粒度，不得为追求更低耗时删除拓扑检查或质量门禁。若处理更大网格，可继续评估拓扑空间索引、掩膜复用和可选诊断输出。
