## 3. 性能解释

当前版本比早期报告的 0.7 秒级结果更慢，主要原因是新增了以下高质量处理：

- 属性约束断层带。
- 根系约束和防误合并策略。
- 残余线性二次追踪。
- 双覆盖保护。
- 更完整的多外环输出和拓扑质控。

这些步骤提升了细弱断层完整性和默认结果稳定性。即便加入上述处理，官方数据总耗时仍约 3 秒，距离 60 秒要求有充足余量。

## 4. 内存风险控制

项目采取以下措施控制内存风险：

- 网格、掩膜、分支和多边形使用连续容器存储，生命周期由对象自动管理。
- CSV、JSON 和 WKT 采用流式写出，避免构造超大中间字符串。
- 拓扑诊断先做包围盒过滤，再做精确线段相交判断，减少临时对象数量。
- GeoEast runner 与核心算法解耦，数据库对象读取后转换为轻量 `Grid2D`。
