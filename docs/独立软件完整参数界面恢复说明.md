# 独立软件完整参数界面恢复说明

## 1. 背景

本次恢复针对 `standalone_app/qt_desktop` 下的独立桌面软件。此前独立软件从 GeoEast 启动器中拆分出来后，界面只保留了少量基础参数，弱响应延伸、属性约束包络、交切短枝、根系防黏连、局部桥防黏连、残余二次追踪等参数仍然由代码写死到命令行中。这样会导致两个问题：第一，用户看到的界面参数不完整；第二，界面显示的处理方案和实际传递给算法的参数不完全一致。

本次修复的原则是：独立软件默认保留外部文件处理、视图预览、算法参数、参数模板、历史记录和导出功能；GeoEast 数据库、项目、用户、BOMapGrid 刷新等内容不作为默认主流程展示。后续根据赛题“独立软件也可读写 GeoEast 数据库”的要求，已将这些内容作为可选【GeoEast数据库】数据源模式加入独立软件，只有用户主动切换数据源时才显示。

## 2. 恢复内容

独立软件已恢复以下参数组。

| 参数组 | 已恢复内容 |
|---|---|
| 追踪参数 | 预设模板、追踪模式、阈值模式、分位数、固定阈值、最小面积 |
| 形态与拓扑约束 | 闭合半径、带宽半径、带后闭合、属性约束断层带、属性包络半径、最大断距、最大夹角、平滑次数、简化容差 |
| 枝干细节与修补 | 弱响应分位、弱延伸半径、最短分支、交切短枝、交切均值、残余二次追踪、补追最短、补追上限 |
| 防黏连参数 | 根系防黏连、根系半径、支撑比例、主体点数、主体比例、弱保护阈值、弱保护半径、局部桥防黏连、低值阈值、桥半径、局部主体、局部比例、桥点下限、低值比例 |
| 显示与视图 | 原始网格、结果多边形、叠加结果、任务预览、颜色、线宽、透明度、平移、放大、缩小、重置视图 |

## 3. GeoEast 数据源内容的边界

以下内容在 GeoEast 集成控件中作为主流程存在；在独立软件中只作为可选数据源模式存在，避免两套产品形态耦合。

| 内容 | 保留位置 | 原因 |
|---|---|---|
| GeoEast 根目录 | GeoEast 集成控件主流程；独立软件可选数据源配置 | 用于配置 GeoEast SDK 和运行库路径 |
| GeoEast 数据根目录 | GeoEast 集成控件主流程；独立软件可选数据源配置 | 用于定位数据库数据目录 |
| 数据库、项目、用户、密码 | GeoEast 集成控件主流程；独立软件可选数据源配置 | 属于 BO 数据库读写配置 |
| 输入 BOMapGrid 下拉框 | GeoEast 集成控件主流程；独立软件可选数据源配置 | 用于选择 GeoEast 数据库中的平面属性网格 |
| 刷新网格列表 | GeoEast 集成控件主流程；独立软件可选数据源配置 | 依赖 GeoEast 数据库连接 |
| 从官方 DAT 导入并覆盖 BOMapGrid | GeoEast 集成控件主流程 | 属于平台对象管理，独立软件以外部文件直接处理为主 |

## 5. 后续维护原则

后续修改界面时必须遵守以下原则。

1. 独立软件不得把 GeoEast 数据库配置字段放回默认外部文件主流程；只能通过可选【GeoEast数据库】数据源显示。
2. GeoEast 集成控件不得删除数据库、网格刷新、写库和导入覆盖功能。
3. 凡是界面显示的算法参数，必须同步进入命令行参数、配置保存和参数模板保存。
4. 凡是显示在工具栏或菜单中的动作，必须有真实功能，不保留空按钮或装饰按钮。
5. 修改后必须至少完成构建、核心烟测、独立默认参数运行和界面截图归档。
