# 第10章 数据说明

## 10.1 数据类型

项目处理的核心数据是二维平面断层属性网格。网格中的数值通常在 0 到 1 或类似范围内，数值越高通常代表断层属性响应越强。输出数据是闭合断层多边形、面积统计、诊断信息和可视化图件。

## 10.2 官方数据

官方数据 `test.dat` 是当前质量验收的正式依据。根据最新报告，导入后的网格规模为 `1501 x 701`。项目中所有算法质量结论都应以官方数据为主，合成数据只用于功能烟测和泛化场景补充。

## 10.3 GeoEast 数据对象

GeoEast 中输入对象为 `BOMapGrid`，输出对象为 `BOFaultPolygon`。用户在 GeoEast 中手动导入 DAT 时，必须注意坐标范围、采样间隔、行列方向和对象命名。如果手动导入参数与脚本导入参数不一致，叠加显示时可能出现结果变成“小点”或位置比例错误。

## 10.4 示例数据

`examples/synthetic/` 保存简单合成网格，适合验证软件能否打开和运行。`examples/synthetic_generalization/` 保存更有针对性的泛化测试，例如交叉断层、断续断层、弱延续、噪声背景、宽断层带和平行不合并。

## 10.5 输出数据

`examples/outputs/` 保存本地历史输出和验收结果。目录由验收脚本按时间生成，不提交到 Git，也不在当前文档中固定引用某个时间戳。当前指标统一以 `docs/官方数据最新验收报告.md` 为准。

## 10.6 数据安全

发布包和 Git 仓库不得包含用户数据库密码、许可证、个人绝对路径或本地实际 `.ini`。仓库只保留不含凭据的配置示例。
