# 第15章 更新日志

## 15.1 当前推荐版本

当前推荐发布版本：

```text
FaultPolyTrace_v1.1.1
```

该版本统一独立软件、CLI和GeoEast插件的200个正式默认结果，补齐完整拓扑、GeoEast事务式写入与逐点回读、数值安全、异常输入、长循环和Windows运行时验证。物理度量、交点簇图、弱连续全局决策、多尺度证据和自适应边界均以影子或复核模式交付，未通过全部晋级门控的候选不会改变正式输出。官方数据默认结果为212个候选、200个保留闭合多边形，CSV SHA256为`2911D696F880E1173F6633E6B8A4587316FDC7DFA19109CE8EB28083A076ED3A`。完整记录见根目录`CHANGELOG.md`。

## 15.2 关键里程碑

| 阶段 | 主要内容 |
|---|---|
| 初始算法阶段 | 实现外部文件读取、阈值分割、闭合多边形输出和面积过滤。 |
| Ridge-Belt 阶段 | 引入基于线性脊线和断层带包络的追踪模式，提高断层带连续性。 |
| GeoEast 集成阶段 | 增加 BO runner、Qt 启动器和主控菜单入口。 |
| 根系防黏连阶段 | 引入骨架拓扑和根系归属思想，降低近邻断层误合并风险。 |
| 产品化界面阶段 | 独立软件和 GeoEast 插件分离，补齐真实图层查看、历史结果、模板、语言切换和引导提示。 |
| 启动性能优化阶段 | 优化本地化索引和非首屏任务调度，增加非模态启动反馈与单实例窗口唤醒。 |
| 流式载入优化阶段 | 网格和多边形预览采用流式解析，核心大文件读写增加缓冲，并减少相同状态下的重复重绘。 |
| 交互绘制优化阶段 | GeoEast DAT 显示使用固定列解析，多边形环预编译为绘制路径，平移缩放不再逐帧转换全部顶点。 |
| 轻量交付阶段 | 发布包只收录当前正式官方结果及必要图件，不携带本机历次性能采样文件，减少下载、解压与安装负担。 |
| 本地化部署校正阶段 | 独立软件与插件显式部署简体中文 Qt 系统对话框翻译，并移除未使用的语言资源。 |
| 满分审计阶段 | 增加发布包验收、参数一致性、客户机可移植性、官方数据审计和现场证据清单。 |
| 物理拓扑与可靠性阶段 | 增加物理尺度、交点簇图、受限弱路径全局决策、完整几何、GeoEast事务回读、ASan、AppVerifier和长循环门控。 |
| 文档归档阶段 | 建立 `PROJECT_INDEX.md` 和 `docs/01-17` 中文文档体系。 |
