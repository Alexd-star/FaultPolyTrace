# 第15章 更新日志

## 15.1 当前推荐版本

当前推荐发布版本：

```text
FaultPolyTrace_v1.0.1-contest-final
```

该版本统一了三入口参数模型和版本化参数模板，具备加载结果后的显示样式实时调整、运行日志保存、结果摘要复制、常用快捷键、GeoEast 写后重读、内环兼容策略、无序对象往返校验、空白视图导出门控、安装器烟测、唯一构建清单和真实现场证据。完整记录见根目录 `CHANGELOG.md`。

## 15.2 关键里程碑

| 阶段 | 主要内容 |
|---|---|
| 初始算法阶段 | 实现外部文件读取、阈值分割、闭合多边形输出和面积过滤。 |
| Ridge-Belt 阶段 | 引入基于线性脊线和断层带包络的追踪模式，提高断层带连续性。 |
| GeoEast 集成阶段 | 增加 BO runner、Qt 启动器和主控菜单入口。 |
| 根系防黏连阶段 | 引入骨架拓扑和根系归属思想，降低近邻断层误合并风险。 |
| 产品化界面阶段 | 独立软件和 GeoEast 插件分离，补齐真实图层查看、历史结果、模板、语言切换和引导提示。 |
| 满分审计阶段 | 增加发布包验收、参数一致性、客户机可移植性、官方数据审计和现场证据清单。 |
| 文档归档阶段 | 建立 `PROJECT_INDEX.md` 和 `docs/01-17` 中文文档体系。 |

## 15.3 提交边界

自动审计未发现硬失败，GeoEast 现场操作截图已经形成步骤索引。正式提交只采用当前统一构建产物及对应证据；旧发布包、历史输出和渲染中间物只保留在本地归档，不进入主分支，许可证和数据库口令禁止提交。
