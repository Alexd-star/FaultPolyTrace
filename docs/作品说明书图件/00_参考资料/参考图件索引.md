# FaultPolyTrace 图件参考索引

## 1. 使用说明

本目录记录作品说明书流程图、算法图、架构图和数据图的设计依据。参考资料只用于研究信息层级、面板组织、字体、线宽、配色和导出规范，不直接复制论文或社交平台图件。正式成图均由 `01_绘图代码` 中的 Python 脚本根据 FaultPolyTrace 当前源码、正式参数和验收数据重新绘制。

检索词包括“科研流程图”“算法框架图”“论文配图”“软件架构图”和“地学算法流程图”。小红书等平台的内容用于观察中文读者熟悉的层级表达、标题长度和配色偏好，不作为科学原理或技术实现依据，也不保存或复制作者图片。检索入口示例：`https://www.xiaohongshu.com/search_result?keyword=科研流程图`。

## 6. FaultPolyTrace 成图规范

1. 成图宽度以 183 mm 双栏图为主，按最终插入尺寸生成，不在 Word 中大比例缩放。
2. 图内中文使用微软雅黑或黑体回退，英文和数字使用 Arial；SVG 保留文字，PDF 使用 TrueType 42。
3. 颜色以深蓝 `#0F4D92`、青绿 `#2A9D8F`、深灰和浅灰为主，橙色仅表示门控或人工确认，红色仅表示拒绝或风险。
4. 不使用渐变背景、阴影、网页卡片、3D 柱、彩色大标题和无意义图标。
5. 箭头表示真实数据或控制流；虚线表示可选、回退或诊断路径；同类对象在全套图中保持同色。
6. 每张图同时输出 SVG、PDF 和 300 dpi PNG，并生成灰度预览；图题和长图注保留在作品说明书中，不烘焙进图内。
