# 第三方软件与许可说明

FaultPolyTrace 的桌面界面和 GeoEast 集成界面动态链接 Qt 5.15.2 运行库。提交包未修改 Qt 库，并以可替换的独立 DLL 形式分发；随包提供 GNU Lesser General Public License Version 3 文本，并明确列出 Qt 官方开源许可说明与源码获取地址。Microsoft Visual C++ 运行库按 Microsoft 可再发行组件形式提供，用于支持 MSVC 2019 编译的 x64 程序。安装器由 Inno Setup 生成，提交包只分发编译后的安装程序，不分发或修改 Inno Setup 本体。

| 组件 | 用途 | 交付形式 | 许可或来源 |
|---|---|---|---|
| Qt 5.15.2 | Windows 图形界面、控件、图像插件和平台插件 | 动态链接 DLL | LGPL v3；https://www.qt.io/development/open-source-lgpl-obligations |
| Microsoft Visual C++ 2019 Runtime | C++ 程序运行支持 | 运行库 DLL 与官方可再发行安装程序 | Microsoft Visual C++ Redistributable |
| Inno Setup 6 | 构建 Windows 安装器 | 仅使用其编译器生成安装包 | https://jrsoftware.org/isinfo.php |
| Python/pytest | 开发和合同测试 | 不随独立软件运行时强制安装 | 仅源码复现与测试使用 |

Qt 官方说明要求在 LGPL 方式下向用户显著告知所用 Qt 库、提供许可证文本，并允许用户替换动态链接库。本提交包采用动态链接方式，不对 Qt DLL 加密或合并。Qt 对应版本源码可从 Qt 官方开源下载渠道获取：https://download.qt.io/archive/qt/5.15/ 。
