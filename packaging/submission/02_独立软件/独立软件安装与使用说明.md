# FaultPolyTrace 独立软件安装与使用说明

## 1. 安装方式

推荐双击 `FaultPolyTrace_Setup_{{VERSION}}.exe` 安装。安装器采用当前用户级安装，不要求管理员权限，默认安装到用户本地应用目录，可创建开始菜单入口，并可选创建桌面快捷方式。安装包已包含 Qt 运行库、图形平台插件、Visual C++ 动态库、核心 CLI、示例数据和中文用户手册。安装完成后从开始菜单启动“FaultPolyTrace”。

如目标计算机不允许安装，可直接进入 `FaultPolyTrace_Portable_{{VERSION}}`，双击 `FaultPolyTrace.exe` 使用免安装版。便携版必须保持目录结构完整，不要只复制 EXE；`platforms`、Qt DLL 和 `bin/faultpolytrace.exe` 都是正常运行所需内容。

支持的正式环境为 Windows 10/11 x64。若旧系统提示缺少运行库，可执行便携版 `prerequisites/vc_redist.x64.exe`，然后重新启动软件。

## 2. 首次使用

软件首次启动时输入文件为空，不会写入开发者电脑路径。用户选择外部平面断层属性文件后，软件读取网格范围和数值统计；在结果尚未生成时，显示区会明确提示当前只有输入数据，没有把原始网格误标为追踪结果。参数区可使用推荐配置，也可按资料品质调整阈值、面积下限、连接距离、断层带半径、平滑和拓扑相关选项。

选择输入文件后，建议先打开“显示原始网格”图层确认数据读取无误，再执行追踪。图层开关彼此独立：可只看原始网格、只看结果多边形，或同时显示叠加结果。结果线条的颜色、线宽和透明度可以在显示属性中修改，这些设置只影响显示，不改变已计算的多边形几何。

## 3. 标准操作流程

1. 启动软件，在数据源中选择“外部文件”。
2. 点击输入文件选择按钮，选择比赛提供的 DAT 或支持的二维网格文本文件。
3. 设置输出目录和结果名称。开始运行前，软件会检查目录能否创建和写入、剩余空间是否足够、输出是否会覆盖输入，并在已有结果将被替换时要求确认。
4. 选择推荐参数或打开已保存的参数模板。面积下限用于过滤规模过小的多边形，不应与显示线宽混淆。
5. 点击【开始追踪】。运行期间界面保持响应，状态区显示当前阶段，完成后显示毫秒和秒两种耗时。
6. 在结果查看区选择“显示原始网格”和“显示结果多边形”，检查叠加关系；使用平移、放大、缩小和适合窗口工具观察局部边界。
7. 根据需要修改结果线条颜色、线宽和透明度。显示属性可随时调整，不需要重新计算。
8. 使用保存或导出功能输出 CSV、诊断 JSON、分支 CSV、拓扑 CSV 和结果图像。历史记录保存本次输入、参数、输出位置和运行状态，便于后续回看。

运行日志可以保存为文本文件，当前结果摘要可以复制到剪贴板，便于记录输入、参数、输出位置、对象数量、拓扑状态和处理耗时。文件菜单、工具栏和常用快捷键指向同一套功能：`Ctrl+O` 打开输入文件，`Ctrl+S` 保存参数模板，`Ctrl+Shift+O` 打开参数模板，`Ctrl+Shift+S` 保存运行日志，`Ctrl+Shift+P` 导出当前视图 PNG，`F5` 开始追踪，`Shift+F5` 停止追踪，`Home` 将视图恢复为适合窗口。

## 4. 参数模板与配置

软件会记住上次正常退出时的窗口状态、输出目录、显示属性和参数设置，但不会把开发测试文件设为新用户的默认输入。点击“恢复默认参数”只恢复追踪与显示参数，不替换用户已经选择的输入文件和输出目录。参数模板采用带格式标识和版本号的 JSON 文件，保存时记录当前可复用计算参数，打开时校验格式、版本、字段类型和取值范围。独立软件与 GeoEast 插件使用同一模板合同，因此模板可以在两个入口之间复用；不合法或超出范围的模板会被拒绝并说明原因，不会静默套用错误参数。

## 5. 输出文件

| 文件 | 内容 | 用途 |
|---|---|---|
| `*.csv` | 闭合断层多边形坐标与属性 | GIS、表格检查或后续系统导入 |
| `*.diagnostics.json` | 网格、阈值、对象数量、耗时和拓扑统计 | 复现和质量核验 |
| `*.branches.csv` | 骨架分支与保留状态 | 算法诊断 |
| `*.topology.csv` | 开放环、自相交和异常相交明细 | 拓扑验收 |
| 导出图像 | 原始网格、多边形或叠加视图 | 报告和人工复核 |

## 6. 常见问题

双击后没有窗口时，应先确认是否只复制了裸 EXE。完整安装版和便携版均已包含 Qt 平台插件；缺少 `platforms/qwindows.dll` 会导致 Qt 程序无法启动。输入官方 DAT 后不应立即点击多个操作按钮，软件会在后台完成数据读取，并通过状态提示更新。若输入为空、不可读，结果名称含有 Windows 禁用字符，输出路径不可写、空间不足或与输入文件冲突，软件会在启动算法前指出具体原因。文档目录被企业策略重定向或不可写时，配置、缓存和默认输出会依次回退到当前用户本地数据目录或临时目录，不会尝试写入受保护的安装目录。

官方数据的正式复现方式见 `../04_复现与验证/官方数据复现与验证说明.md`。
