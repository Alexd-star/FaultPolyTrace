# 官方数据复现与验证说明

## 1. 复现目的

本目录用于证明提交的独立软件安装包、核心 CLI 与正式结果来自同一套算法实现。复现脚本读取比赛提供的 `test.dat`，按作品说明书中的正式参数一次完成追踪，并检查输入文件哈希、多边形数量、几何拓扑和结果 CSV 哈希。脚本不包含本机固定路径，评审人员只需传入官方数据文件位置。

## 2. 一键复现

在本目录打开 PowerShell，执行：

```powershell
.\一键复现官方数据.ps1 -OfficialDat "D:\比赛数据\test.dat"
```

脚本默认调用同一提交包中便携版的 `bin/faultpolytrace.exe`，输出写入本目录下新建的 `复现输出/日期时间` 文件夹。若独立软件放在其他位置，可通过 `-CliPath` 指定。脚本不会覆盖已有结果。

软件界面和一键脚本使用同一正式参数组合。独立软件与 GeoEast 插件首次打开时已经选择“防黏连增强”预设和“正式处理”质量模式，评审人员选择输入数据后可直接运行；Runner 文档中的参数表只是该组合的完整展开，不要求界面用户再次逐项填写。

## 4. 最终结果 DAT 导出与回导验证

一键脚本生成的 `official_result.csv` 是带 WKT、面积和状态字段的内部复现证据，不能仅修改扩展名后作为 GeoEast“断层组合多边形”DAT 提交。最终结果应由 GeoEast 对已写入的 `BOFaultPolygon` 使用【导出断层多边形】生成，从而让 GeoEast 自身正确写出 `faultPolygonName`、`connectionFlag`、`closeType` 以及多多边形分段关系。

本目录已经提供最终 `lc_result.dat` 及配套 `lc_result.fmt`。文件含 200 个闭合外环、62620 行坐标记录，文件大小为 2970079 字节，DAT SHA256 为 `93A5B6441734762F111517AA555372C44B850B51DD295345EBD5FD460C5F4CDC`。结构检查确认八列数据完整、坐标均为有限值、分段编号 1 至 200 连续。GeoEast SDK 事务写入与回读确认 200 个对象、62420 个不重复闭合点，写前和回读规范化几何哈希均为 `050602F47C5FA336`。正式结果不含 GeoEast 无法表达的内环，因而不会在平台显示时把孔洞误填为断层区域。

若作品说明书已经完整列出参数，组委会通知允许不另附参数；为减少复现歧义，本提交仍建议同时附 `参数.txt`，其中明确写出“防黏连增强/正式处理”以及核心参数。

## 5. 安装器烟测

`安装器完整运行检查.json` 记录了正式安装器的完整检查：静默安装到临时目录、检查安装文件、调用安装后的 CLI 处理官方数据、比较正式结果哈希、检查拓扑、确认安装包未混入源码或密钥文件，最后执行卸载并确认主程序已移除。状态 `PASS` 表示该流程全部正常完成。

## 6. 提交包哈希

执行以下命令可检查提交目录在复制或上传后是否发生损坏：

```powershell
.\核验提交包哈希.ps1
```

哈希清单不包含自身，避免递归变化。任何 `FAIL` 都表示文件缺失或内容变化，应重新从原始提交目录复制。
