# FaultPolyTrace 赛题 7 代码提交包说明

## 1. 提交包用途

本目录是“赛题 7：基于平面断层属性的断层多边形自动追踪”作品的正式代码交付包。内容按源码、独立软件、GeoEast 插件、复现验证和第三方许可五部分组织。独立软件与 GeoEast 插件采用不同的界面工程和部署目录，分别适配外部文件作业与 GeoEast 工区作业；二者共享同一套 C++ 断层多边形追踪核心，确保算法参数、输出几何和质量检查口径一致。

提交包仅保留正式功能、必要源码、运行依赖、构建脚本、核心测试和官方数据复现证据。开发过程中的旧版本发布目录、临时输出、调参中间文件、候选实验结果、缓存、个人配置和本机数据库信息均未纳入本目录。

## 2. 目录说明

| 目录 | 内容 | 推荐使用者 |
|---|---|---|
| `01_源码` | C++ 核心算法、独立软件源码、GeoEast 插件源码、构建脚本、必要测试和示例数据 | 评审专家、开发者 |
| `02_独立软件` | Windows 安装器、免安装便携版、安装和操作说明 | 无 GeoEast 环境的用户 |
| `03_GeoEast插件` | GeoEast 主框架插件、集成界面、BO 数据库执行程序、自动部署脚本和操作说明 | GeoEast 用户、现场评审人员 |
| `04_复现与验证` | 官方数据一键复现脚本、正式结果、诊断文件、安装器烟测结果和哈希核验脚本 | 评审专家、测试人员 |
| `05_第三方许可` | Qt、Microsoft Visual C++ 运行库等第三方组件说明和许可文本 | 交付审查人员 |

## 3. 推荐检查顺序

1. 无 GeoEast 环境时，先打开 `02_独立软件/独立软件安装与使用说明.md`，安装 `FaultPolyTrace_Setup_{{VERSION}}.exe`。
2. 需要复现官方数据时，按照 `04_复现与验证/官方数据复现与验证说明.md` 执行一键脚本，并核对多边形数量、拓扑指标和结果哈希。
3. 有 GeoEast 环境时，按照 `03_GeoEast插件/GeoEast插件安装部署与使用说明.md` 部署插件，再从 GeoEast 的“断层多边形追踪”入口运行。
4. 需要审查或重新构建时，阅读 `01_源码/FaultPolyTrace_Source_{{VERSION}}/源码构建与工程说明.md`。

## 4. 统一构建身份

正式二进制由同一轮统一构建生成，构建标识为 `{{BUILD_ID}}`，源码提交为 `{{GIT_HEAD}}`。源码快照哈希、各二进制 SHA256 和运行库哈希记录在各运行包内的 `构建与依赖清单.json`。提交目录全部文件的最终哈希记录在根目录 `SHA256SUMS.txt`，可使用 `04_复现与验证/核验提交包哈希.ps1` 自动核对。

## 5. 支持范围

独立软件支持 Windows 10/11 x64，可读取外部平面断层属性文件，完成参数配置、自动追踪、原始网格显示、多边形显示、叠加显示、样式调整、结果保存和历史记录管理。GeoEast 插件面向比赛提供的 GeoEast 运行环境，支持工区与数据库自动检测、BOMapGrid 输入选择、BOFaultPolygon 结果写入、已有结果查看和删除等工作流。GeoEast 插件二进制与宿主版本有关，若使用不同版本的 GeoEast，应按源码构建说明在目标 GeoEast SDK 环境中重新构建。
