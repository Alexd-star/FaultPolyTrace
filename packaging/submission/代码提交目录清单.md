# FaultPolyTrace 代码提交目录清单

## 1. 清单用途

本清单用于说明赛题 7 作品代码交付包的正式组成。提交目录按“源码、独立软件、GeoEast 插件、复现与验证、第三方许可”五类组织，各部分均对应明确的评审和复现用途。目录中不包含开发缓存、旧版本发布包、个人配置、临时输出或候选实验结果。

## 2. 正式目录

| 路径 | 主要内容 | 使用方式 |
|---|---|---|
| `00_提交包说明.md` | 提交包总览、检查顺序与统一构建身份 | 建议首先阅读 |
| `01_源码/` | 正式源码目录和同内容 ZIP 压缩包 | 用于代码审查、构建和测试 |
| `02_独立软件/` | 安装器、便携版、运行说明和安装器清单 | 用于无 GeoEast 环境下独立运行 |
| `03_GeoEast插件/` | 插件程序、自动部署脚本和使用说明 | 用于 GeoEast 工区集成运行 |
| `04_复现与验证/` | 官方数据正式结果、一键复现脚本、烟测记录和哈希核验脚本 | 用于复现实验与交付验收 |
| `05_第三方许可/` | 第三方组件与许可证文本 | 用于依赖和许可审查 |
| `SHA256SUMS.txt` | 提交目录全部正式文件的 SHA256 清单 | 使用哈希核验脚本自动检查 |

## 3. 三类主要交付物

源码交付物为 `01_源码/FaultPolyTrace_Source_{{VERSION}}/` 及其同名 ZIP。独立软件交付物为 `02_独立软件/FaultPolyTrace_Setup_{{VERSION}}.exe`、`FaultPolyTrace_Portable_{{VERSION}}/` 及其同名 ZIP。GeoEast 集成交付物为 `03_GeoEast插件/FaultPolyTrace_GeoEastPlugin_{{VERSION}}/`、同名 ZIP 和自动部署脚本。

## 4. 一致性说明

CLI、独立软件、GeoEast BO 执行程序、GeoEast Launcher 和主框架插件均来自同一正式源码提交，构建身份和二进制哈希记录在 `04_复现与验证/构建与依赖清单.json`。三份 ZIP 在最终交付阶段由对应正式目录重新生成，压缩包内容与同级展开目录一致。

## 5. 核验方法

在 PowerShell 中运行 `04_复现与验证/核验提交包哈希.ps1`，脚本会读取根目录 `SHA256SUMS.txt` 并逐项核对正式文件。出现 `PASS：提交包全部文件哈希一致。` 表示文件未缺失且内容与清单一致。
