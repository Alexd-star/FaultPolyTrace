# FaultPolyTrace 源码构建与工程说明

本目录是 Git 提交 `{{GIT_HEAD}}` 的完整可审查源码快照，构建标识为 `{{BUILD_ID}}`。源码工作区在构建时为干净状态，核心 CLI、独立桌面软件、GeoEast Launcher、BO Runner 与主框架插件均由该提交统一构建。源码通过 `git archive` 导出，只包含 Git 跟踪文件和本次构建清单，不包含编译产物、发布目录、运行输出、缓存或个人配置。

## 工程入口

- `src/`：C++ 核心算法、输入输出和命令行程序。
- `standalone_app/qt_desktop/`：独立桌面软件 Qt 工程，与 GeoEast 界面工程分离。
- `geoeast_plugin/`：GeoEast Launcher、BO Runner、主框架插件和平台适配代码。
- `tests/` 与 `tests_cpp/`：Python 合同/回归测试和 C++ 核心测试。
- `scripts/`：构建、验收、发布和复现脚本。

## 构建顺序

在 Windows x64、Visual Studio 2019、Qt 5.15.2 和 GeoEast SDK 环境中，依次运行 `scripts/build.ps1`、`scripts/build_desktop_app.ps1`、`scripts/build_qt_launcher.ps1`、`scripts/build_geoeast_bo_runner.ps1` 和 `scripts/build_geoeast_mainframe_plugin.ps1`。无 GeoEast 环境时仍可构建核心 CLI；独立软件构建需要 Qt，插件构建需要与目标 GeoEast 版本一致的 SDK 和 ABI。

完整依赖、参数与测试说明见 `README.md`、`PROJECT_INDEX.md`、`docs/12_环境依赖与部署.md` 和 `docs/13_测试说明.md`。
